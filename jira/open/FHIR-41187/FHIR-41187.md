- **Description**: Profile http://hl7.org/fhir/StructureDefinition/elementdefinition-allowedUnits is referred-to by core R5 metadata files, but there is no metadata file StructureDefinition-elementdefinition-allowedUnits.json included in the core R5 package. Referring items:
. other/spec.internals
. StructureDefinition-elementdefinition-de.json
. xml/elementdefinition-de.sch

Profile http://hl7.org/fhir/StructureDefinition/elementdefinition-question is referred-to by core R5 metadata files, but there is no metadata file StructureDefinition-elementdefinition-question.json included in the core R5 package. Referring items:
. other/spec.internals
. StructureDefinition-elementdefinition-de.json
. StructureDefinition-ElementDefinition.json

This is causing our metadata ingestion to get errors.

It is unclear if those files are unintentionally missing, or if the referring files need to be updated.
