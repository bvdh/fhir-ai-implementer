- **Description**: The given examples in https://hl7.org/fhir/6.0.0-ballot4/dosage-examples.html all use step.component.timing.repeat.count. When is it advised to use the new element DosageDetails.step.count? It seems that all use cases for DosageDetails.step.count can be expressed with DosageDetails.step.component.timing.repeat.count.

What is the difference between DosageDetails.step.count and DosageDetails.step.component.timing.repeat.count?

Suggest to remove step.count from DosageDetails or to add an example for DosageDetails.step.count which cannot be expressed with DosageDetails.step.component.timing.repeat.count.
