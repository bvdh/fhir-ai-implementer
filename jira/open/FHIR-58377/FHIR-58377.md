- **Description**: In the Background and Context, The workflow/clinical status of the composition. table: "The authoring/source system does not know which of the status values currently applies for this observation." Shouldn't it say something other than observation? Also I'm not sure about this but "The composition is unavailable because the measurement was not started or not completed" the measurement part seems odd to me, is that meant to be?

Composition.section.title comment says "section.content" but that element doesn't exist, it is meant to be "section.entry"

Composition.custodian can reference Patient and Group other than "Organization" and the short and long description don't mention "Patient." So maybe we should acknowledge that?

Composition.section.emptyReason has the long definition starts with "If the section is empty, why the list is empty." It should be "section" instead of "list."

Composition.section.focus in the middle of the long definition "If no focus is specified, the focus is assumed to be focus of the parent section," there is a missing "the" before focus.

Composition.participant.function is missing a short description.

There seems to be a discrepancy between Composition.section.entry short and long descriptions, the short says "data that supports this section" and the long says "the narrative in the section is derived" but maybe we could have better wording.

And in the mappings tab: https://build.fhir.org/composition-mappings.html there is a typo that says "assignedEnttty" it should be "assignedEntity" and "DocumenttReference" should be "DocumentReference"

Very small detail but in this example it says "Mpther's Details" replace the p with an o: https://build.fhir.org/composition-example-mixed.json.html
