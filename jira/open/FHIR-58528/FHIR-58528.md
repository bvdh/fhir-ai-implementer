- **Description**: RegulatedAuthorization.case.application uses the same content structure as RegulatedAuthorization.case. Therefore an application contains:

identifier
type
status
date[x]
another application

and can theoretically contain applications recursively.

The definition, however, describes applications simply as regulatory submissions that are steps within the longer-running case or procedure. It does not explain whether applications are themselves intended to contain nested applications.

Suggested change:

Please clarify whether recursive nesting of case.application.application is intentional. If nested applications represent a real regulatory hierarchy, document the intended use and provide an example. If only one level of applications beneath a case is intended, consider constraining the recursive structure or defining a separate application backbone.
