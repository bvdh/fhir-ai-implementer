- **Description**: Library.type is bound extensibly to a list of four codes. I asked Bryn what code I should use to represent CQL, JavaScript, Liquid or other code used to render resources. He said `logic-library`. That code has the definition "The resource is a shareable library of formalized knowledge." Never in my wildest dreams would I have interpreted that definition as "this is the code you use when you want a Library that contains software code." Please update the definition so that the full scope of what can go here is clear. (Also, it's not clear to me that a code this generic is doing anyone any favors. This could be a grocery list, a java program, a diagram of the moon showing particular craters. Who would actually want to filter on something so broad?
