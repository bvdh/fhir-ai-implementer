- **Description**: Based on R6 ballot comments around imaging resources, it would be useful to include DICOM mappings to FHIR datatypes. This ticket covers identifier datatype mappings.

Note: Mapping from DICOM identifiers to FHIR is identifier-type specific so this represents two significant examples. Open to suggestions if there is a better way to represent this.
