- **Description**: The DeviceAssociation references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: deviceassociation-relationship (DeviceAssociation) referenced by ValueSet deviceassociation-relationship bound to element DeviceAssociation.relationship; CodeSystem: deviceassociation-status-reason (DeviceAssociation) referenced by ValueSet deviceassociation-status-reason bound to element DeviceAssociation.statusReason; CodeSystem: deviceassociation-association-status (DeviceAssociationAssociationStatusCodes) referenced by ValueSet deviceassociation-association-status bound to element DeviceAssociation.associationStatus;
