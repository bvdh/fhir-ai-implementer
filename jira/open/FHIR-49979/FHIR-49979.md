- **Description**: In FHIR-49688 the value sets and code systems for BDP and BDPDispense were updated: the maturity levels were set, the immutable flags removed, and some other minor cleanup occurred. The experimental flag was not removed from the value set as there looks to be a tooling issue here.

In the original PR for the Jira there was a change included to set the code systems as example. This was subsequently backed out but it was noted that when the code systems were changed to content type "example" the value sets fail to expand. Rob Hausam reviewed this and had the following comment:

For the biologicallyderived-productcodes, the code system is defined as 'example', with only 9 concepts included. I don't think that the tooling will expand a value set that is defined on an example code system. And it wouldn't be correct to change it to 'fragment' or 'complete', as these codes are the IP of ISBT, and HTA needs to confirm the licensing and agree on an official canonical url for the code system - which I'm sure isn't going to be http://hl7.org/fhir/biologicallyderived-productcodes.

For this ticket the code systems should be revisited to be changed from complete to something else. They are definitely not complete comprehensive codesystems, they are fragments or examples at best. Depending on the decision here there may need to be proper FHIR canonical urls for the code system.

### 3. David Barwin - 2025-08-11

https://build.fhir.org/codesystem-biologicallyderived-productcodes.html
This code system references the ISBT 128 Product Description Code database. This is a proprietary database/valueset used by vendors/implementations licensed by ICCBBA.
More detail: https://www.isbt128.org/p-databases-ref-tables and https://www.isbt128.org/_files/ugd/83d6e1_f20a1200e41a4bb494238473c1f57cdd.pdf

https://build.fhir.org/codesystem-biologicallyderived-product-property-type-codes.html
This code system represents more generic ISBT 128 data elements, specific data contents that have meaning in ISBT 128 terminology.
This value set references ST-027 ISBT 128 Dictionary of Standard Data Elements : https://www.isbt128.org/_files/ugd/1a7593_f5fdde7ad97040f38c68e548c33afbe0.pdf
Each of these data elements are also accessible via URI.
