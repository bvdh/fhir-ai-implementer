"is used to represent a collection of diagnostic data that focuses on the discrete data and their structure/relationship, not an organized document with sequenced sections and entries. ## Comments

### 1. KevinO'Donnell - 2026-09-18

To Hans' comment, Composition is one resource which serves three purposes:

It provides presentation/layout control, to meet human display preferences for other resources (grouping, sequencing, and labelling)
It provides a basic information model, to associate a collection of resources (sections, entries, and some metadata)
It provides a bundle manifest, to create a FHIR Bundle with type=document

By grouping those in one resource it makes it harder to think about one independent of the others.

Some use cases need it for one purpose, some for two, some for all three.

### 2. Russell Ott - 2026-08-13

To discuss at the 2026 Sep WGM - clarifying the intended usage of DiagnosticReport vs. Composition resources.

Note: the only change in the R6 ballot was to add the bullet in the Composition Grouping Structures narrative guidance (https://build.fhir.org/composition.html#2.8.2.2) related to the DiagnosticReport resource. Structurally the references/relationships between Composition and DiagnosticReport have not changed in the R6 ballot.
