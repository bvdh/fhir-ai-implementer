- **Project**: FHIR Specification Feedback

- **Reporter**: Martin von Siebenthal

- **Raised in Version**: R6

- **Related Artifact(s)**: EndPoint
- **Description**: It would be great if Endpoint had an example for a DICOM DIMSE endpoint for DICOM servers that do not support DICOM web. This is needed for example if ImagingStudy or ImagingSelection reference instances that are not accessible through DICOMweb.

<Endpoint xmlns="http://hl7.org/fhir" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://hl7.org/fhir ../../schema/endpoint.xsd">
<id value="example-dimse"/>
<text>
<status value="generated" />
<div xmlns="http://www.w3.org/1999/xhtml">

<text value="DICOM DIMSE"/>
