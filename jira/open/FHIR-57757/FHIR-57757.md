- **Resolution Description**: We will revise the boundaries and relationships section (including the section title) to be:

8.9.2.2 ContactPoint vs. Endpoint

ContactPoint describes how to reach a person, for example, via phone, email, fax, for human-mediated communication. It's embedded in resources like Patient, Practitioner, and Organization.

Endpoint is a full resource describing a system-to-system connection - an API or messaging interface, with protocol, address, etc., for automated exchange.

A ContactPoint and an Endpoint can coexist on the same resource. An Organization might list a phone number (ContactPoint) for patients alongside an API address (Endpoint) for automated referrals.

For Endpoint.contact, we believe the definition exactly describes our intent, but the short display could be improved. We will update the short display to:

Who to contact for troubleshooting or maintenance
