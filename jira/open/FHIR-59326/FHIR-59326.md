# FHIR-59326: CareTeam.participant.member does not allow for an AI

## Metadata

- **Summary**: CareTeam.participant.member does not allow for an AI
- **Created**: 2026-09-21
- **Updated**: 2026-09-21
- **Status**: Submitted
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Grahame Grieve
- **Resolution**: Unresolved
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Patient Care
- **Related Artifact(s)**: CareTeam
- **Description**: CareTeam.participant.member does not allow for Device as a target of the member, which means that it does not allow for an AI to be part of a care team (e.g. home based care surveillance etc)

A similar issue arises with CareTeamparticipant.onBehalfOf though it's less obvious to me that this can be an AI.

Note about AI participations: the question is not whether we would like an AI to do this, or think that it's good practice. The question is: is it impossible for an AI to do this? if it's not, then Device should be one of the possibilities. Note that the participant pattern includes Device (partly for this reason), so not allowing it is also a deviation from the workflow pattern anyway.
