- **Description**: In the descriptions for Evidence.statistic.sampleSize.numberAnalyzed it misspells analyzed as "analayzed" so that needs to be corrected.

Evidence.statistic.attributeEstimate.attributeEstimate's description: "A nested attribute estimate; which is the attribute estimate of an attribute estimate."
That's an odd wording and perhaps an incorrect semi-colon?

Evidence.statistic.category comment says "Simple strings can be used for descriptive purposes." even though it's a CodeableConcept, so maybe mention the "text" element within it.

Evidence.variableDefinition comment says "non comparative" which needs a hyphen "non-comparative"

Evidence.identifier short description says "Additional identifier for the summary". You wouldn't describe an Evidence Resource as a summary. The same issue for the long description too. And same problem for Evidence.version, Evidence.name, Evidence.url, Evidence.title, Evidence.status, Evidence.date, Evidence.approvalDate, and Evidence.lastReviewDate. It can simply be fixed by replacing "summary" with "Evidence" unless there's a better suggestion.
