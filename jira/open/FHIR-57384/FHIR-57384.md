- **Description**: It would be useful to be able to reference a BodyStructure from within the BodyStructure resource. Ideally as a backbone element that can include the reference and a code for the relationship.

Use cases:

Longitudinal measurements of tumors

Multiple tumors may merge as they grow
Single tumors may split under treatment

Hierarchical anatomical structure

e.g. tumor BodyStructure contained in liver BodyStructure

Patient-specific BodyStructure identified as an instantiation of a generic one

### 3. Pieter Edelman - 2026-05-21

If this pattern is being considered, it seems to overlap with the use case described in https://jira.hl7.org/browse/FHIR-56262. It would be preferable to have only a single way to do solve this.

### 4. KevinO'Donnell - 2026-05-21

Another pattern to consider is to allow BodyStructure.includedStructure.structure to reference another BodyStructure resource. This would support hierarchy where, say, an identified calcification structure and a second identified calcification structure are later determined to both be parts of a larger calcification complex. Having BodyStructure 3 have BS1 and BS2 as included structures would clearly communicate the composite nature of the structure and retain the identity of the sub-structures for tracking back to prior observations and treatments on those sub-structures.

### 5. KevinO'Donnell - 2026-05-20

Discussion topic: I think that BodyStructure is about identification of an anatomic or pathologic entity. To characterize that body structure at a point in time, use an Observation. Do not try to capture point in time state and evolution over time in BodyStructure itself.

### 6. KevinO'Donnell - 2026-05-20

Add a use case for "mapping". BodyStructure BS1 is identified and used for an Observation. Later a different system, creates a new Observation on the same entity but since it is unaware of BS1, it creates BS2. Later a third system figures out that BS1 and BS2 are the same entity. It would be nice to put an entry in each pointing to the other as "equivalent" so that subsequent searches can find all the relevant observations.
