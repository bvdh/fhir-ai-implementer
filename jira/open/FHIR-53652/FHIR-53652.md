- **Description**: WCAG 2.1 AA Compliance
Implementations SHOULD strive for WCAG 2.1 Level AA compliance (applicable to narrative div):

Provide text alternatives for non-text content
Ensure content is keyboard accessible
Use clear, hierarchical heading structure

Add Aria attributes

Key Advantage: ARIA attributes work with HTML 4.0 (they're layered on top), so adding them doesn't require moving to HTML5.

Current Gap: FHIR narratives use semantic HTML, but lack the ability to programmatically expose certain relationships and purposes to assistive technologies.

Use Cases in Clinical Narratives:
<!-- Critical allergy alert -->
<div role="alert" class="fhir-alert fhir-allergy">
<strong>SEVERE ALLERGY:</strong> Anaphylactic reaction to Penicillin
</div>

<!-- Status information (lab results summary) -->
<div role="status" class="fhir-summary">
<p>Complete Blood Count: 4 abnormal values detected</p>
</div>

<!-- Major content regions -->
<div role="region" aria-labelledby="demographics-heading" class="fhir-section">
<h3 id="demographics-heading">Patient Demographics</h3>
<!-- content -->
</div>

<!-- Data table (redundant but helpful for complex tables) -->
<table role="table" aria-label="Laboratory Results - Complete Blood Count">
<thead>
<tr role="row">
<th role="columnheader">Test</th>
<th role="columnheader">Result</th>
<th role="columnheader">Reference Range</th>
</tr>
</thead>
<tbody>
<tr role="row">
<td role="cell">WBC</td>
<td role="cell">12.5 K/µL</td>
<td role="cell">4.5-11.0 K/µL</td>
</tr>
</tbody>
</table>
Proposed Attributes:

role (high impact)
aria-label (high impact)
aria-labelledby (high impact)
aria-describedby
aria-hidden

Consider (some) HTML5 Elements
Benefits are incremental (ARIA solves most accessibility gaps)

Proposed Elements:

<figure> and <figcaption> (medical imaging)
<mark> (highlight abnormal values)
<section>, <article>, <aside> (document structure)

No RTL Language Support

The dir attribute is not in the allowed attributes list, yet it is essential for right-to-left languages. "dir" attribute SHALL have one of these values: "ltr", "rtl", "auto".
(Suggestion) Add Accessibility Guidance Section

Narratives SHOULD use semantic HTML elements to improve accessibility:

Headings:

<h3>Patient Demographics</h3>
<!-- Use hierarchical heading levels (h1-h6) -->
Definition Lists (Key-Value Pairs):

<dl>
<dt>Blood Pressure</dt>
<dd>120/80 mmHg</dd>
</dl>

Tables:

<table>
<caption>Laboratory Results</caption>
<thead>
<tr>
<th scope="col">Test</th>
<th scope="col">Value</th>
</tr>
</thead>
<tbody>
<tr>
<td>Glucose</td>
<td>95 mg/dL</td>
</tr>
</tbody>
</table>

Dates and Times:

<time datetime="2025-01-15">January 15, 2025</time>{}

Image Alternatives

All images SHALL include alt text:

<img src="#diagram-1" alt="Patient treatment timeline showing 3 phases" />
