# FHIR-59675: Guidance on properties of type 'code' is inconsistent

- **Description**: On the CodeSystem page in the properties section it says this about properties with the 'code' type: "The values for properties of type "code" (CodeSystem.concept.property.valueCode) are drawn from the codes defined in the CodeSystem instance."

However, if you go to the value set for property.type, the definition says "The property value is a code that identifies a concept defined in the code system or in another code system." (emphasis added)

I'm pretty sure the first statement is correct, so the definition should be updated to remove the bolded part.
