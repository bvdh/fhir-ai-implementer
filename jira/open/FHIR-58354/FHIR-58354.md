- **Description**: While creating Observations in the case, where some, but not all tests in a group can be performed makes sense, it is not clear to me how a system would create a single observation for a canceled panel for example (since the "provider cancelled the order" is one of the examples listed in the text). Currently in V2, if the provider cancels the order the filler will respond with an application ACK either agreeing = to cancel as requested, or informing the placer that the cancelation came to late = unable to cancel. Currently reasons for not performed tests are often just communicated in free text (NTE after the OBR, when no OBX is created; when the reason for cancelation is related to the specimen (e.g. either the type or the condition of the specimen is not appropriate for the ordered test, SPM-21 might be used for a coded response also. When an OBX is present it is sent in OBX-5 (Not desired, because it is not a result), as NTE after the OBX; use of the coded data absent reason element is also possible).

We should reach out to different LIS vendors internationally and determine, if the proposed solution of creating at minimum one OBX segment for canceled orders is implementable before we prescribe this aproach.
