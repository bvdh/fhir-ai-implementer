- **Description**: Both "copyright" and "approvalDate" descriptions mentions a publisher like "When the artifact assessment was approved by publisher" and "When the artifact assessment was last reviewed by the publisher" but publisher is not defined or referenced in the ArtifactAssessment Resource. Is that okay? Also similarly ArtifactAssessment.disposition says "responsible party" but that's not defined neither.

The ArtifactAssessment Resource description says "This Resource provides one or more comments, classifiers or ratings about a Resource and supports attribution and rights management metadata for the added content." But it could have a artifactCanonical instead which could be a non-FHIR Resource.

In Boundaries and Relationships it says "may by referenced" it should be "may be referenced"

This might not be a description really but artifactCanonical has type "canonical()" and not "canonical(Any)" like relatesTo.targetCanonical or artifactReference's "Reference(Any)".

On the mappings tab: https://build.fhir.org/artifactassessment-mappings.html There is placeholder text "N/A (to add?)" which should be replaced.

I'd also review which elements in ArtifactAssessment are isSummary or not. Like ArtifactAssessment.content and elements inside like "summary" should probably be isSummary.
