- **Description**: RDF Turtle resource links are intended to be "SHOULD" suggestions, since these are one of the main benefits of using FHIR RDF.

This is suggested as a "SHOULD" here https://build.fhir.org/rdf.html#primitive-uris

> To facilitate linkage in RDF graphs, if a primitive has FHIR type uri or one of its subtypes (url, canonical, uuid, oid), then a fhir:l property – previously called fhir:link in FHIR R4 – SHOULD be added as a sibling of the fhir:v property.

But then stated as a "MAY" here https://build.fhir.org/rdf.html#reference
> This MAY be represented using the optional fhir:l property

I believe this was a mistake, when the "MAY" was capitalized as part of a general review to make all conformance language conformant. https://build.fhir.org/conformance-rules.html#conflang. The latter section should state "SHOULD" to be consistent with the former.
