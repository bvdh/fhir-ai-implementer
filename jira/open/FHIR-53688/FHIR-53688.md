- **Resolution Description**: In the DosageDetails section of the Dosage page, after the list of typical reasons for multiple components, add:
When components apply to different clinical conditions, each component states the condition it applies to in Dosage.condition, for example with code = problem-presents and details identifying the condition. When the dose is taken only as needed for a condition, that condition is given in Dosage.asNeededFor.
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: In the example reason for multiple components for "different dosages for different conditions", please add a brief mention of how a dosage would be linked to a specific condition. Is that through an element in the .component element (perhaps via the Dosage.condition.details data type element)?
