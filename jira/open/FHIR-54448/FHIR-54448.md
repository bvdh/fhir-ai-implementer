- **Resolution Description**: will change as requested:

"...Where there are multiple dosageInstruction lines (for example, tapering doses), this is the earliest date and the latest end date...."

to: "...Where the dosageInstruction has multiple steps (for example, tapering doses), this covers the whole dosage course, from the start of the first step to the end of the last step..."
- **Description**: Propose changing the effectiveTiming[x]:

from: "...Where there are multiple dosageInstruction lines (for example, tapering doses), this is the earliest date and the latest end date...."

to: "...Where there are multiple steps in dosageInstruction (for example, tapering doses), this is the earliest date and the latest end date...."

Reason: dosageInstruction is now 0..1 (single), so the "multiple lines" scenario is handled differently in R6.
