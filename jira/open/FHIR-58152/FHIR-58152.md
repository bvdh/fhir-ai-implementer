- **Resolution Description**: Remove Composition.useContext and provide examples, and guidance with respect to relationship and use of these elements:

Element Id
Composition.category

Definition
A categorization for the type of the composition - helps with indexing and searching. This may be implied by or derived from the code specified in the Composition Type.

Element Id
Composition.type

Definition
Specifies the particular kind of composition (e.g. History and Physical, Discharge Summary, Progress Note). This usually equates to the purpose of making the composition.

Element Id
Composition.classification

Definition
The assignment to an organizing scheme, including the type of classification and one or more classifier values.
- **Change Category**: Clarification
- **Change Impact**: Non-compatible
- **Description**: The R6 Composition includes 3 different elements to 'categorize' the resource.

category
useContext

Please consider removing useContext and clarify how the others relate to each other. Also, if only for Evidence Based Medicine, make it clear.

### 4. KhalidShahin - 2026-09-22

anja.schwab@elga.gv.at,
We originally added useContext to the Composition Resource for a similar reason that you gave, but it turns out that's an improper use of useContext, so we added a new element, Composiiton.classification, which is a backbone element with a classification.type CodeableConcept and classification.classifier CodeableReference.

The reason useContext is improper for what you described is because it's meant to be defining How or Where the Resource is meant to be used, in a clinical context. The new classification element is meant to describe what you said which is where the Composition information came from (or how it was made).

Does the new Composition.classification element cover what you need for this?

### 5. AnjaSchwab - 2026-08-17

Please do not remove useContext. When the composition is used like it is described in Scope and Context for "Using Composition for Context-Establishing Snapshots" then the useContext is essential for conveying the context under which the snapshot was created - e.g. the workflow step that lead to this composition.
