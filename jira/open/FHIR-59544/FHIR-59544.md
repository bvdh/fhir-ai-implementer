- **Resolution Description**: We will add a new search parameter:

Name: address

Type: uri

Description: The technical base address for connecting to this endpoint

Expression: Endpoint.address

We note that the uri search param type calls out :above and :below, so we aren't planning to mention those modifiers in the Endpoint page, but not that if a reader clicks into the uri type, they'll see those modifiers listed: https://build.fhir.org/search.html#uri
- **Resolution Vote**: Adam Culbertson / Joe Lamy : 4-0-0
- **Vote Date**: 2026-10-06
- **Change Category**: Enhancement
- **Change Impact**: Non-substantive
- **Description**: It is impossible to search Endpoints by the address used.

Add a search parameter for Endpoint.address.

It is suggested to mention the :above modifier, so a search value of "http://foo.com/a/b/c" matches an endpoint address of "http://foo.com/a"
