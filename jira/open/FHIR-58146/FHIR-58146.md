- **Description**: The definition and comments are not clear as to what the purpose of the relationship is. Suggest adjusting the defintiion to state:

"Any resource to which the creation of this record is tightly associated, not already addressed in DocumentRefernece.relatesTo.

Suggest adjusting the comment to state:

"Use only for references not covered in DocumentReference.relatesTo, for example references at the data or workflow level."

If that is not the intent, open to another clarification that would not use "other document reference lifecycle elements" as that terminology only appears in a definition, not in a name that can be easily found.
