- **Description**: The following text appears beneath all resource definition the following language:
Additional definitions: Master Definition XML + JSON, XML Schema/[Schematron|https://build.fhir.org/messagedefinition.sch] + JSON Schema, ShEx (for Turtle) , the spreadsheet version & the dependency analysis, and See the Extensions for this resource.
The XML and JSON definition is labeled as informative. Although they are used to generate the UI representation, from a specification point of view, they are not leading.

As such labeling them as "Master definition" is misleading and might lead people to treat them as leading over the UI representation.

Suggested alternative language:
Additional definitions: XML + JSON, XML Schema/[Schematron|https://build.fhir.org/messagedefinition.sch] + JSON Schema, ShEx (for Turtle) , the spreadsheet version & the dependency analysis, and See the Extensions for this resource
