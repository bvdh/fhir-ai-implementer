- **Description**: PlanDefinition.actor.option.typeReference and PlanDefinition.action.participant.typeReference
both allow Device, but not DeviceDefinition.
It states "When this element is a reference, it SHOULD be a reference to a definitional resource", so I assume DeviceDefinition would be preferred here, but I suppose because it is a SHOULD, that Device should be retained.
SubstanceDefinition was added recently, and Substance retained, even though this would usually be a definition not an instance.

Same applies to ActivityDefinition.participant.typeReference. Needs DeviceDefinition
