### 3. Carmela A. Couderc - 2026-07-27

Discussed on the tracker call 20260727

Note that displayLanguage is not related to the return of designations - specifies the language that the display element in the expansion should be returned in. Whereas the designation parameters define which designations should be included.

This proposed resolution would be persuasive with mod.

Update the designation parameter documentation to:

> A token that specifies a system and code (using [system]#[code] syntax) that is either a use or a language as defined for the concepts in the CodeSystem. Designations that match by language or use with this parameter value are included in the expansion. If no designation is specified, it is at the server discretion which designations to return. Note that this parameter is ignored if includeDesignations is false.
