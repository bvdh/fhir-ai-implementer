- **Description**: The publishing machinery should enforce that CodeSystem.content for code systems with a canonical URL with a base of "hl7.org" (i.e. terminology.hl7.org, hl7.org/fhir, etc.) must always be 'complete'.

All code systems that HL7 defines are ones that, by definition, we define the complete set of codes in. Therefore, there's never any situation where the CodeSystem instances we produce would be anything other than the complete set of codes. Similarly, there's no reason for HL7 to ever supplement its own code systems. If we want something in one of our code systems, we should put it there.

This is a tooling change, but before the tooling change can occur, we first need the blessing of the TSMG.
