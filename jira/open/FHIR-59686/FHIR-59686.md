From: "...the “Presence” state of an alert signal (e.g., monitor beeps or not) depends on the “Presence” state of the triggering condition, the “Activation” state of the triggering condition (e.g., detectable or not), and the “Activation” state of the signal itself."

To: "...the “Presence” state of an alert signal (e.g., monitor beeps or not) depends on the simultaneous occurrence of the triggering condition, the “Activation” state of the triggering condition (e.g., detectable or not), and the “Activation” state of the signal itself."

- **Description**: Issue description
There is a residual statement in the second-to-last paragraph of section 11.2.1 that refers to an earlier version of DeviceAlert, when it had a .presence element.

Proposed change
From: "...the “Presence” state of an alert signal (e.g., monitor beeps or not) depends on the “Presence” state of the triggering condition, the “Activation” state of the triggering condition (e.g., detectable or not), and the “Activation” state of the signal itself."

To: "...the “Presence” state of an alert signal (e.g., monitor beeps or not) depends on the simultaneous occurrence of the triggering condition, the “Activation” state of the triggering condition (e.g., detectable or not), and the “Activation” state of the signal itself."
