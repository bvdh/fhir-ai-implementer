I saw the notes got added https://build.fhir.org/request.html#code, which includes a comment about the new "other" code
The 'Other' code is reserved for use where none of the existing codes are applicable
I actually thought at May WGM that J#56142 was going to be revisited, so I was surprised when it got applied.

What is the plan for this?
1) to re-open J#56142 and no longer add "other" --> this means the notes paragraph needs to be modified
or
2) keep the resolution and another PR is coming to add the "other" code to code system and value set
