- **Description**: Current Comment:

The various reasons for an empty section make a significant difference to its interpretation. Note that this code is for use when the entire section content has been suppressed, and not for when individual items are omitted - implementers may consider using a text note or a flag on an entry in these cases.

The value set contains 6 concepts (https://hl7.org/fhir/6.0.0-ballot5/valueset-list-empty-reason.html) and not a single code as part of the Comment implies. The comment also implies the coding will be used, when text or coding can be used. It also implies the section content is ALWAYS suppressed, when in fact in the value set there is no "Suppressed" but the synonym term in the set is " withheld", the other members of the set supply other reasons for emptyiness

Proposed Comment text change:

The reason a section is empty is important to its interpretation and may be conveyed using text or coding. The bound value set represents multiple reasons for the absence of section content, including withheld content. This element applies to the section as a whole; omission of individual entries may instead be conveyed using a text note or flag on the entry.
