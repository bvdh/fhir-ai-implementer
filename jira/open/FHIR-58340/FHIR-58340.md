- **Resolution Description**: Make two sentences, one about simple Observations, and one about Organizer Observations.

Replace:

"The Observation.code indicates the nature of the observation or panel (e.g. individual measure, organism isolate/sensitivity or antibody functional testing). "

With:

When the Observation is a simple observation, Observation.code represents the nature of the observation (e.g. Glucose Measurement, TSH Measurement).
When the Observation is an organizer, Observation.code represents the name of the organizer/panel/group (e.g. CBC, RFT, LFT, DICOM SR Measurement Group).

Also add an explanation, about the usage of Order Only codes in Observation.code/DiagnosticReport.code

To Observation:

When the Observation is an organizer, the specification make sure that no value is present, but Observation.code may be discordant with some code systems for order only codes.

To DiagnosticReport:

When the DiagnosticReport is an organizer, DiagnosticReport.code may be discordant with some code systems for order only codes.
- **Description**: The Observation.code indicates the nature of the observation or panel (e.g. individual measure, organism isolate/sensitivity or antibody functional testing).

This sentence represents what .code represents when using pattern#2 and should make that clear.

For pattern#1 .code represents the entire report; When the report contains a single Observation or a single panel the codes in DiagnosticReport.code and in the grouper Observation.code could be the same, otherwise .code is a higher level code that desribed the type of report.
