- **Resolution Description**: service-type, service-category, program, service-referral-mode, and service-provision-conditions value sets are already in THO. The spec will need to be updated to point to those value sets instead.

specialty was previously agreed-upon to move to THO in OrgAffiliation and PractitionerRole, so should align with that.

- **Change Category**: Enhancement
- **Change Impact**: Non-substantive
- **Description**: The HealthcareService references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: eligibility (Eligibility) referenced by ValueSet eligibility bound to element HealthcareService.eligibility.code; CodeSystem: service-mode (ServiceMode) referenced by ValueSet service-mode bound to element HealthcareService.characteristic;
