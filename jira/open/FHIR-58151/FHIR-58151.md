- **Description**: A list of issues on the BP profile:

The text summary of requirements states "additional Coding repetitions representing a more specific code for the measurement obtained MAY be included in Observation.code." This is incomplete, also alternate codes from other code systems such as MDC can be present. This also applies to the texts for Observation.component.code.
The detailed descriptions have this text: "This is a grouping structure. It has no value in Observation.valueQuantity but contains at least one component (systolic and/or diastolic)." This is in conflict with the profile requiring 2 or more components.
The profile requires two components or more, but it should be allowed that both are absent and Observation.dataAbsentreason is present instead with value "not-performed" for example.
