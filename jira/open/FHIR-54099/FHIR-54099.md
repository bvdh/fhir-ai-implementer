MedicationStatement includes an adherence element. Note that this adherence is specific to that instance of MedicationStatement. If MedicationStatement.adherence is being tracked over time, then instances of MedicationStatement would report adherence for the interval noted in effectivePeriod.

with
MedicationStatement.adherence describes whether the patient is actually taking the medication: for example, whether it is being taken, is on hold, has been stopped or is not being taken, and, when known, whether this is as directed. MedicationStatement.adherence.reason can explain why. Adherence is distinct from MedicationStatement.status, which describes the state of the statement record itself (recorded, draft or entered-in-error), not the patient's use of the medication.
The adherence is specific to the MedicationStatement instance in which it appears and applies to the interval in MedicationStatement.effective[x]. When adherence is tracked over time, each change is recorded as a separate MedicationStatement instance that covers its own interval.
- **Description**: In the scope and usage section at
https://hl7.org/fhir/6.0.0-ballot4/medicationstatement.html#scope, there is the following paragraph:
"MedicationStatement includes an adherence element. Note that this adherence is specific to that instance of MedicationStatement. If MedicationStatement.adherence is being tracked over time, then instances of MedicationStatement would report adherence for the interval noted in effectivePeriod."
I suggest adding an introductory explanation describing the purpose of MedicationStatement.adherence. This would help readers better understand the paragraph and the intended use of the element.
