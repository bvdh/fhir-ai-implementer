- **Description**: The Extended Resource Types value set (https://hl7.org/fhir/6.0.0-ballot5/valueset-extended-resource-types.html) references a code system with URI

http://hl7.org/fhir/tools/CodeSystem/additional-resources

It is recommended that this code system be one published in HL7 Terminology (THO) with a terminology.hl7.org URI. Reasons for this include more open and transparent changes to the code system under the THO publishing and the UTG process (changes would be pro-forma based on decisions from FMG).

If the recommendation is followed, the Extended Resource Types value set definition will need to be changed to reference the new code system.
