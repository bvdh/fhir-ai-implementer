# FHIR-57389: Consider whether DiagnosticReport should have a direct relationship to ImagingSelection

- **Description**: The HL7 EU imaging diagnostic report profile includes (via extension) references to ImagingSelection resources identified as findings or impressions.

The baseline DiagnosticReport resource does not include a direct relationship between these two resources. It is possible to include an ImagingSelection only indirectly via having an included Observation – either in results or conclusionCode be derivedFrom an ImagingSelection.

Is this a gap in DiagnosticReport?

Some approaches considered in discussion with O&O:

Add ImagingSelection to allowed media references
Add ImagingSelection to allowed supportedInfo references
Add ImagingSelection to allowed results references
