- **Description**: The CodeSystem.property.uri element's comment recommends populating the element with a value where the URI string consists of [code system URL]#[code], and this format is widely adopted in HL7 specification.

This ballot comment recommends this following:

When using the recommended forms ([code system URL]#code, can the comment also indicate how the code system's version can be included? Perhaps as [code system URL]|[version]code ?
Adding a short form to reference properties defined in the current code system.
Adding what is meant by the "formal meaning" of a property and what sources (if any) other than a code system these can come from. If URI formats for other sources can be provided, this would also be helpful to include.
