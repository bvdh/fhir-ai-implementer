- **Description**: I have a case where an FML map has the following using the append transform:

uses "http://hl7.org/fhir/StructureDefinition/Patient" as source
uses "http://hl7.org/fhir/StructureDefinition/Patient" as target

group TransformAppend(source src : Patient, target tgt : Patient) {
src.name as v -> tgt.name as tn then {
v.family as f, v.text as t -> tn.text = append(f, ' ', t) "r1";
v.family as f, v.text as t -> tn.text = append(f, ' - ', t) "r2";
v.family as f, v.text as t -> tn.text = append(f, ' ', t) "r3";
} "r2";
}

This will need to create a parameter to the target transform:

<target>
<context value="tn"/>
<element value="text"/>
<transform value="append"/>
<parameter>
<valueId value="f"/>
</parameter>
<parameter>
<valueString value=" "/>
</parameter>
<parameter>
<valueId value="t"/>
</parameter>
</target>

or for another example, one where the value in the middle is a dash with whitespace each side - which isn't really recommended either...

"parameter" : [
{
"valueId" : "f"
},
{
"valueString" : " - "
},
{
"valueId" : "t"
}
]

https://build.fhir.org/ig/HL7/mapping-language-ig/en/examples.html#transform—append

Error message reported in an IG gives these:
%Primitive types should not only be whitespace
%value should not start or finish with whitespace ' - '
