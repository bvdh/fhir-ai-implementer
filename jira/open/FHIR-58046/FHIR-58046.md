- **Description**: The Implementation Support module would benefit from an informative page describing current best practices and implementation considerations for using FHIR data as input to LLM-based AI systems.

Increasingly, AI architects and developers are required to work with FHIR data despite not being FHIR experts, and such guidance would provide a valuable starting point for understanding how to effectively leverage FHIR data while avoiding common pitfalls.

Topics could include context selection, representation approaches, token efficiency, preservation of clinical meaning and semantics, provenance and traceability, grounding, safety considerations, and performance optimization. Providing this guidance would help promote more consistent, interoperable, and safer implementation patterns across the industry.
