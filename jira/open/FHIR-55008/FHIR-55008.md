- **Resolution Description**: We will add Device to the targets of MedicationRequest.performer, next to DeviceDefinition. This allows an order to name a specific device that performs the administration itself (for example, for instance orders). It aligns with the Request pattern (Request.performer includes Device) and with MedicationAdministration.performer.actor. When the device is only used for the administration, it goes in device (see FHIR-54416). Update the request mapping exceptions, where Device is listed as missing.
