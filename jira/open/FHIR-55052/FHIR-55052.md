- **Description**: The RegulatedAuthorization references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: regulated-authorization-type (RegulatedAuthorizationType) referenced by ValueSet regulated-authorization-type bound to element RegulatedAuthorization.type; CodeSystem: product-intended-use (ProductIntendedUse) referenced by ValueSet product-intended-use bound to element RegulatedAuthorization.intendedUse; CodeSystem: regulated-authorization-basis (RegulatedAuthorizationBasis) referenced by ValueSet regulated-authorization-basis bound to element RegulatedAuthorization.basis; CodeSystem: regulated-authorization-case-type (RegulatedAuthorizationCaseType) referenced by ValueSet regulated-authorization-case-type bound to element RegulatedAuthorization.case.type;
