- **Description**: In https://hl7.org/fhir/6.0.0-snapshot1/obligations.html#obligations, the spec currently says:

For further details about how to use the obligation extension, consult the extension documentation.

In https://build.fhir.org/ig/HL7/fhir-extensions/StructureDefinition-obligation.html, it says:

See the Obligation page in the core specification for further detail.

The combination of the two sections doesn't really give a lot of detail on how Obligations are used in IGs such as examples or more extensive usage notes. It seems like each part of the recursiveness assumes the other will have that detail.
