- **Description**: As requested in https://jira.hl7.org/browse/UP-849:

Add two new values to the Detected Issue Severity code system (https://terminology.hl7.org/7.2.0/en/ValueSet-detectedissue-severity.html), which is used for the DetectedIssue.severity element.

The new values should be:
contraindicated: indicates the issue is identifying a clinical action that is contraindicated
unknown: indicates the severity of the issue is unknown

This code system should be updated as part of the R6 specification.
