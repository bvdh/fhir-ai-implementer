## Comments

### 1. Lloyd McKenzie - 2026-04-09

NOTE: There are existing servers that return 'false' instead of 'empty' when invoking htmlChecks on strings right now. This means that when this is rolled out, some old servers will report an error when they encounter it. (This might be a good thing from a safety perspective, but may be frustrating from a compatibility perspective.)
