- **Resolution Description**: The ballot note is misleading and should have acknowledged the change occurred in an extension. The note indicating the extension name on the resource itself is correct.

As the ballot note is specific to ballot5 and will be removed before next ballot cycle (or normative) it seems inappropriate to fix the note to balloters after the fact.

- **Description**: The Ballot Note states that Device.conformsTo was updated to carry a source and align with the equivalent element on DeviceDefinition. However, Section 11.1.5.4 indicates that source is represented using the device-conformsTo-source extension rather than as a Device.conformsTo.source element.

Please consider clarifying the Ballot Note to explicitly state that the alignment is achieved through an extension, as the current wording "updated to carry a source" may suggest that a new subelement was added to the Device resource.
