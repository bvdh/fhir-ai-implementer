# FHIR-54024: Add Rationale to reaction severity

- **Related Artifact(s)**: AllergyIntolerance
- **Description**: The criteria for assessing the severity of a symptom may vary. If a severity is reported as an Observation, .method can be used to clarify the criteria used, but severities carried at the .reaction level don't have a way to clarify how the severity was evaluated. Add a property (rationale, criterion or method) to the model to clarify the meaning of the severity element.
