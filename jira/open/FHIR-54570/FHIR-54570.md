The W3C Provenance Model in Plain English:
This model answers one simple question: "Where did this thing come from, and how did it get here?"
The Three Building Blocks

Concept
Plain meaning
Examples

Entity
A thing (a noun)
A document, a dataset, a photo, a report, a version of a file

Activity
Something that happened (a verb)
Editing, compiling, attesting, transforming, copying

Agent
Who or what is responsible
A person, a piece of software, an organization

How They Connect

An Activity uses one or more Entities as input
An Activity generates one or more Entities as output
An Agent is responsible for an Activity
An Entity can be attributed to an Agent
An Entity can be derived from another Entity

The "last hop" (the last organization making a meaningful clinical update to the data and the prior system providing it)...
