- **Description**: Affected element:

`TestScript.setup.action.assert.stopTestOnFail`

The definition states:

> Whether or not the current test execution will stop on failure for this assert.

The short description asks:

> If this assert fails, will the current test execution stop?

However, the comment states:

> If this element is specified and it is true, then assertion failures should not stop the current test execution from proceeding.

The comment reverses the meaning expressed by the element name, definition and short description.

Please correct the comment so that `true` means that execution stops when the assertion fails, and `false` means that execution proceeds. Please also clarify whether “current test execution” means the current test or the complete TestScript, including the expected behaviour for an assertion in `setup`.
