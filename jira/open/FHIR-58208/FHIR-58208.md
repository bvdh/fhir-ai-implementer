- **Description**: ResearchStudy.phase currently has Preferred binding to ResearchStudyPhase defined in THO. However, all the values in this value set have relevant codes in NCI Thesauruse and/or SEVCO code systems. It is preferred to use terms from these established code systems instead of using another terminology that will not be further maintained in THO. The BRR WG wants to replace the binding for ResearchStudy.phase with a preferred binding to a value set using codes from the NCI Thesaurus (Including all the codes required in ICH M11 regulatory reports) and an additional binding (preferred) to a value set using SEVCO codes (for implementations that re-use the SEVCO codes found in ResearchStudy.studyDesign elements)
