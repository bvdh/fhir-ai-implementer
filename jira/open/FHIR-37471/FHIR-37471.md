- **Resolution Description**: Now that we have moved extension definitions out of the core spec, we will do the following:

Update the publisher to be able to check the core spec and any dependency IGs for use of extensions defined in that IG
Update the tooling to render such cross-referenced examples in the examples tab for the extension
Spit out a warning if there are no examples that reference an extension either in the extension IG itself or an ancestor
Set an expectation for work groups to clean up all said warnings.
