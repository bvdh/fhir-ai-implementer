- **Description**: In the following paragraph there is a non-conformance 'may' that can cause confusion:

If all the parameters for the operation are primitive types and the operation has affectsState = false, the operation may be invoked by performing an HTTP GET operation where all of the values of the parameters are appended to the URL in the search portion of the URL (e.g. after the '?' character). Servers SHALL support this method of invocation. E.g.

Propose changing to:

If all the parameters for the operation are primitive types and the operation has affectsState = false, the operation is also invokable by performing an HTTP GET operation where all of the values of the parameters are appended to the URL in the search portion of the URL (e.g. after the '?' character). Servers SHALL support this method of invocation. E.g.

### 1. Yunwei Wang - 2024-04-08

If all the parameters for the operation are primitive types and the operation has affectsState = false, client application MAY invoke this operation by performing either HTTP GET operation where all of the values of the parameters are appended to the URL in the search portion of the URL (e.g. after the '?' character), or HTTP POST operation. Servers SHALL support both methods of invocation
