- **Description**: Binding for DocumentReference.context.event is to v3 Code System ActCode with example strength. The value set includes all codes and is in THO.

This binding should not be to an "all codes" value set as there are many concepts in the code system that are not appropriate and could be misleading. Create a value set with all descendants of _ActCredentialedCareProvisionPersonCode or _ActEncounterCode or _ActMedicalServiceCode (or all 3 hierarchies) and bind to that instead.

Assuming the corresponding C-CDA binding may be impacted as well.
