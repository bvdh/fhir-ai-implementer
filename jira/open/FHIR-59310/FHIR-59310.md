# FHIR-59310: MedicationDispense doesn't allow for an AI to be responsible for subtitution

## Metadata

- **Summary**: MedicationDispense doesn't allow for an AI to be responsible for subtitution
- **Created**: 2026-09-20
- **Updated**: 2026-09-22
- **Status**: Waiting for Input
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Grahame Grieve
- **Resolution**: Unresolved
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Pharmacy
- **Related Artifact(s)**: MedicationDispense
- **Description**: MedicationDispense has a participate for substitution.responsibleParty which is not allowed to be a Device - but it seems like AI might be responsible for the substitution. For this reason, Device should be allowed

Note about AI participations: the question is not whether we would like an AI to do this, or think that it's good practice. The question is: is it impossible for an AI to do this? if it's not, then Device should be one of the possibilities. Note that the participant pattern includes Device (partly for this reason), so not allowing it is also a deviation from the workflow pattern anyway.

- **Jira**: https://jira.hl7.org/browse/FHIR-59310

### 1. Jose Costa-Teixeira - 2026-09-22

We understood this is not about being good practice or happening now. We looked at "given the intent of the element, is it impossible to ever have an AI?"

The case considered was a device (doesn't even need to be an AI) that is in an automated dispenser, and as part of that dispense, there is a decision to substitute - e.g. dispense 2 500mg tablets instead of 1 1000mg tablet. Isn't the responsibleParty still the organization?

When AI participates in the decision to substitute, does this also go into .performer which is a key-value pair ?

If in the case cited (or any case) if there is an AI, the group agreed that we can change the definition of the element and give such use case as an example.

We looked for cases of unfinished dispenses but that also doesn't seem to show an AI being responsible. Also automated dispensing doesn't seem clear that it would be an AI responsible for the substitution - it would still be an organization.
