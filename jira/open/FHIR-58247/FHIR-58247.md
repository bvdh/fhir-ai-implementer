- **Description**: Recommended rules for case 3 pattern:

The Observation.code is preferably a LOINC or SNOMED CT concept code.

If a SNOMED CT concept code is used, the expression SHOULD represent a 404684003 (Clinical finding (finding)), 413350009 (Finding with explicit context(finding)), or 272379006 (Event(event)).

Do we really want to have a mismatch between a LOINC - which represents either evaluation or observable entity and the clinical finding hierarchy here? It would be good to document the rationale, why it is ok to not use observable entity for this pattern, but not ok for patterns 1 and 2.
