- **Description**: Currently there is no invariant, no guidance for preventing to create a BodyStructure resource which could have an includedStructure with the exact content as the excludedStructure, and syntactically it would be validated and stored in a FHIR server. This scenario shall be prevented as it is non-sense to say it is included AND excluded at x structure. Of course it needs to be considered to assess the whole structure as it could be that it is the same structure, same laterality but a different qualifier.

If you guys don't want to create an invariant to prevent this, please at least provide guidance in order to avoid such situations.
