- **Description**: This text is unlcear: "ObservationDefinitions are only to be used when describing the contents of an observation (including observations in order catalogs or panels). When additional structure, sequence, or rules are needed, the Questionnaire resource should be used."

It seems to imply that a catalog that includes panels with reflex tests (the sequence of tests according to specific rules) should use Questionnaire for that? The Questionnaire resource does not allow for linkage to specimenDefinition or DeviceDefinition, so to me, that is not really a correct statement.
