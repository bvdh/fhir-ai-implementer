- **Description**: A medication list that contains every medication in a patient's history is too large to read effectively. But active-only may be too restrictive: some providers prefer a Medication list to contain not only currently but recently active medications. In order to support such a search, we are working on an IG to specify
a) a cancel date extension for prescriptions that have been stopped
b) an active-end search parameter that selects the earliest of the cancel date extension or .dispenseRequest.validityPeriod.end

This would be a lot more useful if it were in the core.

(We also specify a statusHorizonDuration parameter in an "essential-medication-information-for-review" Operation, and we publish both the Operation definition and query guidance. But even the query won't work without an active-end parameter.)
