- **Specification**: FHIR Core (FHIR)

- **Grouping**: ready-for-vote
- **Description**: All conformant FHIR Applications SHOULD use these labels where appropriate.

My impression is that very few "FHIR applications" (which is presumably applications that interoperate FHIR) use security labels.

I seems bad to have this normative verb be so far from the current reality on a Normative page. Please change the language to indicate that this statement is aspirational, or provide evidence that it's not or remove it.
