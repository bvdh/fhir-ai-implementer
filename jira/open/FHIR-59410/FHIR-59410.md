Resource / element: Dosage.patientInstruction (datatype, used by MedicationRequest, MedicationDispense and MedicationStatement via DosageDetails)

Description:
Dosage.patientInstruction ("Instructions in terms that are understood by the patient or consumer") is currently a string. Patient-oriented dosing instructions often need more than plain text:

Pictograms for low-literacy or multilingual patients. Standard sets exist, e.g. the FIP and USP pharmaceutical pictograms. These are widely used in community pharmacy and in low- and middle-income settings.
Simple formatting: emphasis on warnings, and line breaks between morning, midday and evening doses.

R6 already allows images in markdown to reference a contained Binary or DocumentReference by #id (narrative.html, "Image References"; Binary notes). But the only markdown element available is DosageDetails.renderedInstruction. That element is a rendering of the structured dosage, not separate content for the patient, and a system may regenerate it from the structured dosage, which would drop the images.

Proposed resolution:

Change the type of Dosage.patientInstruction from string to markdown.
Add a comment to the element saying that images such as dosing pictograms may be included using the markdown image rules in narrative.html (Image References), referencing a Binary contained in the resource that holds the Dosage.

Impact: Non-substantive in practice, since existing string content is valid markdown. Technically a breaking type change, but Dosage already has breaking changes in R6 (DosageDetails), so this is the right release to make it.

Grouping: Related to the broader review of medication resources for community pharmacy and non-institutional settings.
