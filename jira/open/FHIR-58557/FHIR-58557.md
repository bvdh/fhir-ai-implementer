- **Description**: Tthe following Group Resource Search Parameters look like they need to be fixed:

characteristic-quantity has has in the expression "reference: value.ofType(Reference))" where it has an extra closing parenthesis without a corresponding opening
<component>
<definition value="reference"/>
<expression value="value.ofType(Reference))"/>
</component>
I see that there is both characteristic-quantity and quantity and they both look like for kind of the same thing. I believe the one named just "quantity" was meant to be for just Group.quantity and not the characteristic.valueQuantity, so we should fix that.
The "code" search parameter's description seems wrong and should be reworded. The "code" description is too similar to the "type" search parameter description.

I also suggest adding these Canonical search parameters to the Group Resource (unless they come with the interface automatically already)

title for Group.title
description
version
date
publisher
context
context-quantity
context-type-quantity
context-type-value
context-type
