- **Resolution Description**: We will apply the suggestions as follows, together with the "Statements of no known medications" section added for FHIR-54566(https://jira.hl7.org/browse/FHIR-54566):

1. Scope and Usage, common usage: add "the recording that a patient has no known medications (see Statements of no known medications)".
2. Narrative with codes: the new section names SNOMED CT 787481004 |No known medications| and states that national editions may provide more specific codes. National codes, such as 1234391000168107 |No known current medication| from SNOMED CT-AU, are not listed individually.
3. MedicationStatement.medication comment: add "For a general statement that no medications are known, the code does not identify a product or class of products. For a statement that a specific product or class is not known to be taken, a code that expresses that is used. See Statements of no known medications."
4. MedicationStatement.status: no specific text is added. The status has the same meaning for these statements as for any other: the state of the record (the codes listed in the ticket are no longer current). A link to the new section is added to the status comment.
5. MedicationStatement.effective[x] comment: add "For a statement that no medications are known, this is the time or period for which that is asserted. If absent, no inference can be made about the period to which the statement applies."

We will also correct example 10 (medicationstatementexample10): remove the header comment, which describes a different scenario ("not taking now but will be taking in future").
- **Description**: Note to Balloters has this statement: The MedicationStatement.medication element now explicitly supports representing statements such as 'no medications are known / taken.'

Given this expanded scope of use, some changes need to be considered to improve clarity and facilitate correct usage for this "no known medication" use case.

Suggested changes:
(1) Scope and usage section:
Common usage examples - add "no known medication"

(2) Scope and usage section texts to include narrative texts, e.g.: The MedicationStatement scope and usage has been expanded to support "no known medication". In this use case, (a) MedicationStatement.medication - CodeableConcept may include a SNOMED CT code, e.g. 787481004 | No known medications | 1234391000168107 | No known current medication

(3) MedicationStatement.medication
Comments field (https://hl7.org/fhir/6.0.0-ballot4/medicationstatement-definitions.html#MedicationStatement.medication) to include additional comment texts:
If it is a global statement about "no known medication", the MedicationStatement.medication element should not identify a specific product or a specific class of product.
In the use case of negation statement about a specific product or a class of product, this MedicationStatement.medication element should contain a "no known" code for a specific product or class of product.

(4) MedicationStatement.status:
Comments field (https://hl7.org/fhir/6.0.0-ballot4/medicationstatement-definitions.html#MedicationStatement.status) should include additional narrative:
In the context of "no know medication" use case, it represents the status of "no known medication" statement at the point when it was asserted. The value set for MedicationStatement.status contains a limited set of active | entered-in-error | unknown.

(5) MedicationStatement.effective[x]
Comments field (https://hl7.org/fhir/6.0.0-ballot4/medicationstatement-definitions.html#MedicationStatement.effective_x_) should include additional texts:
In the context of "no known medication" use case, this attribute reflect the dateTime or the period/duration over which no information is known about patient taking any medications. If this data element is unvalued | unpopulated, no inference can be made about the timing on the "no known medication" assertion.
