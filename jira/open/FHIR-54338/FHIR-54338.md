- **Resolution Description**: Both levels are needed, so the element is added rather than moved:

Add DosageInstruction.additionalInstruction (DosageDetails is renamed DosageInstruction by FHIR-54340): 0..*, CodeableConcept, same example binding as Dosage.additionalInstruction (AdditionalInstruction). Short: "Supplemental instructions or warnings that apply to the whole dosage course". Definition: "Supplemental instructions to the patient or warnings about the medication that apply to the whole dosage course, across all its steps and components (for example, "may cause drowsiness; do not drive or operate machinery")."
Keep Dosage.additionalInstruction for instructions that apply only to one component (for example, "with food" for the scheduled dose but not for an as-needed dose). Comment on both elements: an instruction that applies to the whole course is given once on DosageInstruction.additionalInstruction and is not repeated in each component.

Rationale: instructions can differ between components, so they cannot be moved; but a warning that applies to a stepped course (for example a titration over several steps, see FHIR-59569) currently has to be repeated in every component, or put in one component where it reads as applying only to that step. Keeping Dosage.additionalInstruction remains consistent with FHIR-54336 (route stays at Dosage level).
- **Description**: Are there usecases where multiple Dosage.additionalInstruction elements can differ from eachother within the same DosageDetails element? Isn't the Dosage.additionalInstruction for each MedicationRequest the same? Suggestion to move Dosage.additionalInstruction to DosageDetails.additionalInstruction.
