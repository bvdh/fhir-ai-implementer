- **Description**: The search parameter currently describes DeviceAlert.signal.presence as: "Whether the alert is currently occurring"

However, its expression is DeviceAlert.signal.presence describes whether signal annunciation is occurring and why—for example on, latched, off, or acknowledged.

A latched signal is a state or alarm that remains continuously active even after the condition that originally triggered it has disappeared. It requires a manual action—such as pressing a reset or clear button—to return to its normal state.

DeviceAlert.signal.presence does not directly indicate whether the underlying alert condition is currently occurring. This distinction is especially important in Ballot 5 because the former top-level DeviceAlert.presence was removed. For example, a latched signal can still be annunciating after the alert condition has ended.

Proposed change:

Change signal-presence Search Parameter Description From:

"Whether the alert is currently occurring"

to something such as:

"The presence/annunciation state of the alert signal."
