- **Resolution Description**: The specification is already able to handle non-FHIR data. CDA, v2, CSV, or other data can be pointed to as an instance. It would simply be a Binary reference. The IG tooling can determine (or be informed of) the appropriate mime type the Binary has and, if appropriate, can even indicate the logical model the instance is to be validated against.

We will update the spec to include an ExampleScenario that shows exchanges and examples of non-FHIR data.
