- **Resolution Description**: As discussed on 20 May 2026: no core element is added. The existing timing-exact extension on Timing.repeat indicates that the stated times are to be followed as precisely as possible. We will ask FHIR-I, which owns the Timing datatype, to add narrative guidance on how stated times are interpreted (generally or exactly) and on the use of the timing-exact extension.
- **Description**: Some dosing instructions (for example antibiotics) specify times that must be followed as closely as possible.

Suggestion to add an element to Dosage Safety "timingExact". See the modifier extension http://hl7.org/fhir/StructureDefinition/timing-exact in https://simplifier.net/packages/nictiz.fhir.nl.r4.medicationprocess9/2.0.0-rc.1/files/2841288
