- **Description**: The Organizer element description does not address semantics.

"FHIR resources are independent, so there is no context conduction, as there is in CDA. As a result, Observations in a panel do not share, e.g., a specimen unless they severally assert references to the same specimen."

This is a significant nuance that should be made clear in the comments.
