- **Description**: Code system properties can be defined by concepts in code systems.

For example, in FHIR core standard, the Concept Properties FHIR code system defines standard properties. This helpfully allows the CodeSystem.property.uri element to be populated with a URI in the form <code system URI>#<property concept> value.

However, when FHIR CodeSystem instances contain concepts which define properties, there is clear machine processable way to assert that the concept defined a property.

To address this, this change request proposes that the following new property be added to the Concept Properties FHIR code system:

code: isProperty
display: Is Property
definition: The concept defines a a code system concept property.
dataType: boolean

Additionally, the new concept should be added to the Defined Concept Properties subsection (https://build.fhir.org/codesystem.html#defined-props).

Lastly, when considering this change request, a discussion is recommended on whether to explicitly add this property with a value of 'true' to the Concept Properties FHIR code system's concepts. Semantically, this makes sense because these concepts are indeed all property definitions. However, this would mean that the definition of the isProperty concept itself would require use of itself which might hinder understanding or processing of the code system. Alternatively, the definition could state that all concepts in the code system have this property with the implicit value of 'true'.
