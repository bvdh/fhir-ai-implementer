- **Resolution Description**: Motion to create a FHIR code system in THO that combines HL70936 and HL70937 into one hierarchy that then can be referenced in DiagnosticReport.supportingInfo.type. Add to the description on the THO page to clarify that this new code system is a combination of two HL7 v2 tables that are managed in v2 through two fields that in FHIR are managed using one attribute.

Once created, update the valueset to link to this new code system and keep the binding on DiagnosticReport.supportingInfo.type as Example and remain informative.
- **Resolution Vote**: Juno Anzalone / Kevin O'Donnell : 6-0-1
- **Vote Date**: 2026-09-24
- **Change Category**: Enhancement
- **Change Impact**: Compatible, substantive
- **Description**: The DiagnosticReport references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: diagnosticreport-relevant-information-types (DiagnosticReportRelevantInformationTypes) referenced by ValueSet diagnosticreport-relevant-information-types bound to element DiagnosticReport.supportingInfo.type;
