- **Description**: In R4 and R5, ResearchStudy.relatedArtifact supported the RelatedArtifact datatype. The R6 version difference states that this element was replaced by ResearchStudy.relatesTo, with a "possibly incomplete mapping."

The new structure is not fully equivalent. RelatedArtifact can associate a formatted citation, label or display text with a URL or resource reference. ResearchStudy.relatesTo only provides a relationship type and a single target[x] choice, so this information cannot necessarily be retained within one relationship.

Please review whether RelatedArtifact should be supported directly by ResearchStudy.relatesTo, or otherwise ensure that existing use cases, particularly bibliographic references and conversion from R4/R5, remain representable.
