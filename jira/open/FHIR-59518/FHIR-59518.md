- **Description**: https://build.fhir.org/fhir.ttl shows primitive types with min 1 cardinality, but these should all be min 0 cardinality, except for xhtml. This likely wasn't caught before because OWL min >0 cardinality usually consistent with any "missing" RDF data unless it adds closure axioms, which FHIR RDF doesn't (and shouldn't). Anyway this is a small technical correction.
Example: https://build.fhir.org/boolean.profile.ttl
Xhtml: https://build.fhir.org/xhtml.profile.ttl

2. https://build.fhir.org/fhir.ttl does not encode base definition relationships between primitive type classes, like it does with other classes. This is a mistake and we should see, for example "code" as a subclass of "string". This is due to Kindling's differences with accessing primitive types, which won't be an issue if/when the code that derives this is ported to the core library. Example: https://build.fhir.org/code.profile.ttl
