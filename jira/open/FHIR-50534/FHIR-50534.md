- **Resolution Description**: Change the binding of observation.code to LOINC (Example).

Additional Note: We described in Diagnostic Module Page how to handle the different grouping patterns.

Observation as a grouper is allowed (see Pattern #1) and using DiagnosticReport as a Grouper for a panel (see Pattern #2) also. See below:

Pattern #1: The entire diagnostic report (as created by the fulfiller of the order(s)) is represented by a bundle containing one DiagnosticReport resource for the patient for a particular point in time. Some concepts, such as panels, are always represented as Observations, where Observation.code equals the panel code, and Observation.organizer is true.
Pattern #2: The entire diagnostic report (as created by the fulfiller of the order(s)) is represented by a bundle containing one or more DiagnosticReport resource instance(s). The DiagnosticReport resource represents a group of tests (e.g. a panel) usually performed together.

- **Description**: If the grouping discussion elects to use Observation this element is critical to ensuring that systems have an explicit way to identify any observations that are NOT true observations, but rather groupers. Currently the example in the Diagnostic Module for micro results the reflex Susceptibility panel Observation resource is linked via the organism identified Observation.HasMember and it uses the Susceptibility panel Observation.hasMember to link to all antibiotics defined for that panel. That Observation resource would show .organizer = true.

Use of this element will enable a more stringent valueset definition for Observation.code when .organizer = true then: codes from LOINC, where Order vs. Observation = "Order Only" or Both"

When .organizer = false, then: codes from LOINC, where Order vs. Observation = "Obs Only" or Both"

This will also facilitate finding all true observations (.organizer = false) as well as all groupers (while the same code could also be located in ServiceRequest.code or DiagnosticReport.code, this would be the most granular level at which all groupers/panels are found)
