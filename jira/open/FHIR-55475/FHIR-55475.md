### 1. Carmela A. Couderc - 2026-10-05

The definition of maximum is as follows:

If the main conformance binding has strength = extensible, then any codes used to extend that value set SHALL come from this specified "maximum value set". Note that this additional binding replaces the extension http://hl7.org/fhir/StructureDefinition/elementdefinition-maxValueSet extension which is no longer defined in FHIR Release 5+ This is deprecated - it is equivalent to required
