- **Description**: udiCarrier.deviceIdentifierSystem vs udiCarrier.issuer - **

Both elements capture issuer-related information:

deviceIdentifierSystem: "Establishes the namespace for the issuing agency's system (e.g., GS1's GTIN, ICCBBA's ISBT-128)"
issuer: "Organization that is charged with issuing UDIs for devices"

The relationship and distinction between these two elements is unclear. Both are URIs, both relate to the issuing organization. When would these differ? This creates implementation confusion about which to populate and when.
