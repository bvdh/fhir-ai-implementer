# FHIR-53440: Update ActivityDefinition to use new DosageDetails type

- **Related Artifact(s)**: ActivityDefinition
- **Description**: ActivityDefinition.dosage 0..* Dosage is no longer 'correct' because Dosage datatype changed extensively. It used to be that Dosage.sequence would allow combining multiple Dosage instances. Dosage.sequence no longer exists in changes just applied to R6. It looks like ActivityDefinition.dosage 0..* Dosage should be changed to ActivityDefinition.dosage 0..1 DosageDetails or ActivityDefinition.dosageDetails 0..1 DosageDetails. Note that one of the examples of ActivityDefinition was changed to match changes in Dosage datatype and the sequencing of this example is no longer structurally explicit.
