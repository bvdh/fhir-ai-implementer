- **Resolution Description**: We will update the definition and short display of Account.diagnosis.use to match what is in Encounter.diagnosis.use:

So Account.diagnosis.use will now be:

Definition
Role that this diagnosis has within the account (e.g. admission, billing, discharge …).

Short Display
Role that this diagnosis has within the account (e.g. working, final …)

Today, the value sets do match (they all use the exact same value set). However, we did consider moving that to THO in https://jira.hl7.org/browse/FHIR-55290, but ended up deciding not to.
