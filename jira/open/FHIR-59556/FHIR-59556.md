- **Description**: When defining a concept map, there are times that a non-mapping value could use property information.

For example, in cross-version mapping, we want to be able to annotate specific non-mapping codes as `unsafe` to translate.

Currently, there is no mechanism to add properties to an `element` that has `noMap`.
