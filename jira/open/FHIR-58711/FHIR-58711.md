- **Resolution Description**: Repeats (refills) are a specific functionality that has to be explicitly authorized. When numberOfRepeatsAllowed is absent, no repeats are authorized; only the original dispense is allowed. We will:

Add meaningWhenMissing to MedicationRequest.dispenseRequest.numberOfRepeatsAllowed: "If absent, no repeats are authorized: only the original dispense is allowed."
Add to the definition, after "A prescriber may explicitly say that zero refills are permitted after the initial dispense.": "Repeats are only authorized when this element is present with a value greater than zero."
Mark numberOfRepeatsAllowed as a summary element (isSummary = true), and therefore also MedicationRequest.dispenseRequest, so that the number of authorized repeats is included in summary views.

The element is not made a modifier element. A modifier is an element whose omission or ignoring leads to an unsafe misinterpretation of the resource. With this meaning, a system that ignores the element assumes no repeats are allowed, which is the conservative interpretation, so it does not need to be a modifier.

## Comments

### 1. Heath Frankel - 2026-10-07

As mention by GrahameGrieve this ticket was raised as a result of discussions in Australia on how to interpret the non-existence of numberOfRepeatsAllowed.

In particular, this was in the context of medicines charts used in hospitals and residential care facilities where it is common to have an ongoing supply authorisation where the number of authorised supplies is unspecified, the authorisation is time bound rather than a specified number (i.e. the validity period of the medication chart).

It was concluded that a single supply would require numberOfRepeatsAllowed = 0 to explicitly support this case.

This would allow a missing numberOfRepeatsAllowed to support the ongoing supply authorisation, which would then need to have a validity period specified.

The proposed resolution is clearly indicating that a missing numberOfRepeatsAllowed is equivelent to numberOfRepeatsAllowed =0.

This means there is no ability to the ongoing supply authorisation requirement for medicines charts.
