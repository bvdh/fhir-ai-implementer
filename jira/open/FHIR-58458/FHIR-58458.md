- **Description**: The display of an implicit concept representing a Measure.group.stratifier.component is mapped to CodeSystem.concept.display but these elements have incompatible types string/CodeableConcept.

A CodeableConcept may contain text and multiple Coding entries. The specification does not define how an implementation should select the single string required for CodeSystem.concept.display.

Please clarify this mapping.
