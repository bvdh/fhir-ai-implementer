- **Description**: Imaging Diagnostic Report has a list of relevant prior imaging studies and reports made available to the radiologist when reporting a current study. The list is generally created by a pre-fetch algorithm. Reports explicitly state when no relevant priors were available.

Need a code that is like nilknown but can be used by a computer/algorithm.

e.g. "searchfailed - An automated search for relevant items was conducted. Either the available items were determined to be not relevant or no items were determined to be available. I.e. it was determined the content of this list is appropriately null."

"nilknown" says it is asserted by a user, not a computer system.

"unavailable" - says it is for when the PACS was down, not when everything worked correctly and it's simply a null list.
