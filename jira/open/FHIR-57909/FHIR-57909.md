- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Orders & Observations
- **Outstanding Negatives**: Normative
- **Related URL**: https://hl7.org/fhir/6.0.0-ballot5/specimendefinition.html
- **Related Artifact(s)**: SpecimenDefinition
- **Description**: In R5 this resource was Trial Use at FMM 1 — the lowest maturity level, indicating essentially no cross-vendor production track record. Ballot 5 proposes promoting it directly to Normative while simultaneously making substantial model changes in the same cycle:
* Subject re-modeled (FHIR-54840): the subject[x] choice (CodeableConcept | Reference(Group)) reduced to subjectReference (Reference(Group) only).

Container re-modeled (FHIR-53723): material, type, cap, capacity, and description removed in favor of device[x], relocating those attributes onto DeviceDefinition (material.substance, description, and property entries). This migration is partial — height/diameter were not added, and the DeviceDefinition.property.value[x] that now carries cap color / container type is unbound (no suggested vocabulary), where R5 offered example bindings.
Additive re-modeled: additive[x] choice replaced with type (CodeableReference(SubstanceDefinition)) plus a new quantity.
Identifier cardinality relaxed 0..1 → 0..*.

Each of these is a reasonable evolution for a Trial Use resource. Taken together, they are direct evidence that the model is still actively changing this cycle and has not "seen widespread use in production across the full spectrum of environments it is intended to be used in" — which is the bar for Normative. Promoting it now would lock a model that is demonstrably still in flux and remove the ability to correct issues that real-world use would surface.

As a concrete data point: Epic — a vendor with broad laboratory and specimen data — does not expose SpecimenDefinition through its FHIR API today (it supports the separate Specimen instance resource at R4 only). A resource this central to lab catalogs going unimplemented by a major vendor is itself a signal it has not reached Normative-level adoption.

Proposed resolution: Keep SpecimenDefinition at Trial Use. Let the re-modeled subject/container/additive structures be exercised in real implementations before locking the resource Normative.
