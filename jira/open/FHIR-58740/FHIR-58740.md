- **Resolution Description**: Update cmd-12 to:

(noMap.exists() and noMap=true and %resource.status != 'draft') implies comment.exists()
- **Description**: The below example element map will fail the cmd-12 best practice invariant. (returns empty - which is a failure)

{{{}}
{{ "code" : "male",}}
{{ "target" : [{}}
"relationship" : "related-to",
"code" : "M"}{{{}]{}}}
{}}

Maybe something like:

(noMap.exists() and noMap=true and %resource.status != 'draft') implies comment.exists()

similar to cmd-4
