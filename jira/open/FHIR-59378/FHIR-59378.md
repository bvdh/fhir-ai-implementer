- **Description**: This page https://build.fhir.org/integrated-examples.html has been around since DSTU1, but is a bit broken.

The table at the end "Intakes", shows a Substance resource for Potassium, but it is no longer part of the scenario. The care plan on that table row used to have substance of Potassium. But it was changed some time ago to use a NutritionProduct.

Basically the resources linked to this page have been updated, and the scenario page has not.

There are now no substances relevant to this scenario, so the Potassium reference at least should be removed, and probably the whole Substance column.

Should we remove that column? This came up because the Substance resource for Potassium is going to be deleted (it's meaningless as an instance), and this was the only place that appeared to need it (but actually doesn't really seem to).
