- **Description**: Element:
DeviceAlert.derivedFrom.component

Current wording:

"Repetitions of this element indicate additional components contributing to the alert condition."

Issue:
DeviceAlert.derivedFrom.component has cardinality 0..1, so repetitions of this element are not possible. The parent DeviceAlert.derivedFrom element has cardinality 0..* and can be repeated to represent additional Observation/component combinations.

Suggested wording:

"Additional components contributing to the alert condition may be represented using additional derivedFrom repetitions."
