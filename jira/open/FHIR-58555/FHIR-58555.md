- **Resolution Description**: Add ResearchStudy.progressStatus.instance 0..1 dateTime "The point in time when it occurred", also add an invariant so that .instance and .period cannot both occur in the same .progressStatus
- **Description**: `ResearchStudy.progressStatus.period` only permits a `Period`, although many status changes and registration activities occur at a single date or dateTime.

Using only `Period.start` implies that the period remains ongoing, while using only `Period.end` indicates that its start is unknown. Neither accurately represents a point-in-time event.

Please consider renaming the element and allow both point-in-time and interval representations, for example through an `effective[x]` or `occurrence[x]` choice of `dateTime | Period`. The same change should be considered for the `period` element of the StudyRegistration extension.
