- **Resolution Description**: Remove the Extensions for rendering data elements page.
Review the Profile List Page to see if there is any content that needs to be preserved or moved. If not, remove the Profile List and various generated stub files (e.g., Common extensions for Identifier data type). Most linked files have only the boilerplate language in them. If there is content that needs to remain, remove the entries that contain no content.
EITHER add to the Narrative / Presentation Related Safety Checks on the Safety Checklist or create a new page about rendering:

> When displaying resource content, my system checks for rendering extensions on elements when appropriate (e.g., rendered-value, rendering-markdown, rendering-xhtml).

> When generating or updating resource content, my system checks for rendering extensions on elements when appropriate (e.g., rendered-value, rendering-markdown, rendering-xhtml).
- **Description**: The page https://build.fhir.org/rendering-extensions.html mentions extensions but does not list any. The same page in R5 has the same problem.

I asked Lloyd McKenzie, and he wrote, "That page shouldn't be there. It's where some of our extensions used to live before they got moved to the extensions pack. "

So, I guess this page should be deleted.
