- **Description**: Somewhere under BodyStructure or Observation, there should be guidance (and possibly an "expand" parameter) for invoking anatomical search expansion.

If I want to pull a patient cardiac info form the records, I might search for Observations where patient=X and bodyStructure=<heart>, but it won't return any of the observations where bodyStructure=mitral valve, or left ventricle, or descending coronary artery, etc. etc. Similar issue searching for Conditions.

Given that the SNOMED anatomical code tree establishes the relevant parent-child relationships, can we offer a search parameter that triggers the server to apply the tree to expand the search results to relevant sub-anatomy, or is the guidance that it's the responsibility of all clients to access the anatomy tree and include the 97 relevant sub-anatomy codes in their search?
