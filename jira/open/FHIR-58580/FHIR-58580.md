- **Description**: By definition, the TerminologyCapabilities.validateCode element refers to the $validate-code on ValueSet operation. However, this is not apparent if viewing an instance of the TerminologyCapabilities resource type and may be mistake to apply to the $validate-code on CodeSystem operation.

To avoid the confusion, this change request recommends renaming the element to "valueSetValidateCode".
