- **Description**: case.status is defined only as “The status associated with the case.” but is also bound Preferred to PublicationStatus.

A regulatory case/procedure would normally have process states such as submitted, under review, pending information, approved, rejected, withdrawn, closed, etc. PublicationStatus, by contrast, describes the lifecycle status of an artifact (draft, active, retired, unknown).

This distinction becomes particularly important because the specification defines a case as the administrative process that assesses regulatory applications.

Suggested change:

Please review whether PublicationStatus appropriately represents the lifecycle of a regulatory case/application. Consider using a case/procedure-specific value set or providing implementation guidance explaining how regulatory process states should be represented.
