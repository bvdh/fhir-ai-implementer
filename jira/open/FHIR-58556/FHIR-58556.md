- **Description**: The ValueSet/$expand and ValueSet/$validate-code operations have a manifest parameter that allows an "artifact manifest" to be used to provide defaults for the values of parameters to the expand or validate-code operation.

The parameter definitions refer to the trial-use Canonical Resource Management Infrastructure (CRMI) implementation guide for some definitional aspects, as well as some additional clarifying guidance. The definitional aspects of the representation of an artifact manifest and how the manifest parameters are specified and applied for $expand and $validate-code should be incorporated into the specification by:

1. Create a ManifestParameters parameters profile (see https://hl7.org/fhir/uv/crmi/en/StructureDefinition-crmi-manifestparameters.html)
2. Create a ManifestLibrary profile that specifies:
a. inputExpansionParameters 0..1 cqf-inputParameters, profiled to reference ManifestParameters
b. usedExpansionParameters 0..1 expansion-parameters, profiled to reference ManifestParameters
c. expectedExpansionParameters 0..1 cqf-expansionParameters, profiled to reference ManifestParameters
3. Create a ManifestImplementationGuide profile that specifies:
a. inputExpansionParameters 0..1 cqf-inputParameters, profiled to reference ManifestParameters
b. usedExpansionParameters 0..1 expansion-parameters, profiled to reference ManifestParameters
c. expectedExpansionParameters 0..1 cqf-expansionParameters, profiled to reference ManifestParameters
3. Add an Artifact Manifest section to the terminology module that explains how manifest parameters are represented and used (Artifact Manifest section 5.2.1 in CRMI STU2: https://hl7.org/fhir/uv/crmi/en/version-manifest.html#manifest
4. Update the manifest parameters in $expand and $validate-code to:

Specifies a library or implementation guide that provides expansion rules for the operation by referencing a contained Parameters resource that is used to provide default values for other parameters to the operation. See the Artifact Manifest topic in the terminology module for more information on how manifests are represented. Parameters specified directly in the invocation override parameters in the manifest.

5. Add a manifestParameters parameter in $expand and $validate-code:

manifestParameters 0..1 Parameters - Manifest parameters used to provide default values for other parameters to the operation. This parameter cannot be used at the same time as the manifest parameter. See the Artifact Manifest topic in the terminology module for more information on how manifest parameters are applied. Parameters specified directly in the invocation override parameters in the manifest.
