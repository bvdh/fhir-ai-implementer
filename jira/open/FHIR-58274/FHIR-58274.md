Element Id
DeviceAssociation.status

Definition
Indicates the state of the Device Association. The status describes the status of the DeviceAssociation record itself (e.g., administrative or lifecycle reasons for the record state), not the state of the underlying device relationship.

DeviceAssociation.status explicitly represents the status of the DeviceAssociation record itself, not the underlying device relationship, and statusReason provides reasons for that status. However, the DeviceAssociation Status Reason Code definitions repeatedly state that the "relationship status changed." This wording may incorrectly imply that the codes describe DeviceAssociation.relationshipStatus.

Proposed change:

Revise the CodeSystem definitions so they explicitly describe changes/reasons related to the DeviceAssociation record status, not relationshipStatus.

For example:

"The DeviceAssociation record status changed because the record was archived."

Similarly, review all codes to distinguish record-state reasons from relationship-state reasons.
