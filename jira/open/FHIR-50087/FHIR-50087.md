- **Created**: 2025-03-20

- **Resolved**: 2025-05-14
- **Status**: Resolved - change required
- **Project**: FHIR Specification Feedback

- **Resolution**: Persuasive with Modification
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R5
- **Work Group**: FHIR Infrastructure
- **Related URL**: https://build.fhir.org/codesystem-actordefinition-actor-type.html
- **Related Artifact(s)**: ActorDefinition
- **Resolution Description**: For ActorDefinition.type:
1. We will change the binding to person | system | collective | other and leave as required and defined in FHIR
2. We will add a new element "category" 0..* CodeableConcept with a 'preferred' binding to a value set that excludes the 'system' code and makes 'collective' abstract. Will move that code system to the THO spec.

short: Kind of entity acting

definition: A more detailed description of the type(s) of entity that can function as the actor
- **Resolution Vote**: Gino Canessa/Brian Postlethwaite: 6-0-0
- **Vote Date**: 2025-05-15
- **Change Category**: Correction
- **Change Impact**: Non-compatible
- **Description**: The usage scope of these codes is very likely to extend beyond FHIR core. In order to facilitate more timely additions of new Actor types, moving to THO is advised.

Here are some examples that are in an under-development IG that might be good candidates to add to this CS. https://build.fhir.org/ig/HL7/fhir-us-ndh/CodeSystem-IgActorCS.html
