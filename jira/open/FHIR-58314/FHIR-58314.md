- **Description**: The comments on the use of Group to indicate the type of subjects, breeds, etc. that the specimen can be collected from are confusing. A Group can be defined as a series of characteristics and/or specific members, which would seem reasonable for describing the kind of subjects that this specimen can be obtained from. But then we should not use Group.type it seems too restrictive as cardinality is one. What if a specimen can be collected from a person or animal or other specimen or etc.? One would have to create different specimen definitions for essentially the same specimen kind. It seems that Group.type should then be empty and .characteristics should be used. To be consistent, characteristics should always be used and one of the codes is for "type" and one can include multiples as appropriate.
