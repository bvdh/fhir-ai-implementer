Define a new parameter for $expand, $validate-code (ValueSet and CodeSystem) $lookup CodeSystem $translate ConceptMap (this addition supports identification via uri+version, or canonical)

Name: canonical

Type: canonical

Cardinality: 0..1

$expand: Identifies the value set to be expanded as an optionally-versioned canonical reference. It is an error to use this parameter when the operation is invoked on an instance or if `url` `valueSet` `valueSetVersion` are provided.

$validate-code Value Set: Identifies the value set to use for validation as an optionally-versioned canonical reference. It is an error to use this parameter when the operation is invoked on an instance or if `url`, `valueSet`, or `valueSetVersion` are provided.

20260831:

$validate-code CodeSystem: Identifies the code system to use for validation as an optionally-versioned canonical reference. It is an error to use this parameter when the operation is invoked on an instance or if `url` or `codeSystem` are provided.

20260914

$lookup: Identifies the code system to use for lookup as an optionally-versioned canonical reference. It is an error to use this parameter when the operation is invoked on an instance or if `version` or `codeSystem` are provided.

$translate: Identifies the concept map to use for translation as an optionally-versioned canonical reference. It is an error to use this parameter when the operation is invoked on an instance or if `url` or `conceptMap` are provided.

New parameters with same type and cardinality as canonical

$translate: sourceCanonical Identifies the source code system to use for translation as an optionally-versioned canonical reference. It is an error to use this parameter when `sourceSystem` is provided.

$translate: targetCanonical Identifies the target code system to use for translation as an optionally-versioned canonical reference. It is an error to use this parameter when `targetSystem` is provided.

$translate: sourceScopeCanonical Identifies the source value set to limit the $translate output as an optionally-versioned canonical reference. It is an error to use this parameter when `sourceScope` is provided.

$translate: targetScopeCanonical Identifies the source value set to limit the $translate output as an optionally-versioned canonical reference. It is an error to use this parameter when `targetScope` is provided.
