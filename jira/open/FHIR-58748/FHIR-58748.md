- **Description**: There's situations in some code systems where the result of $subsumes is actually unclear to the server.

One example is SNOMED-CT where two expressions that have not been classified are being compared - the server can be confident in some situations but it can't know in others

the same applies in mime types, for instance, if there is unknown qualifiers.

So servers should be able to return some variant of cannot-determine
