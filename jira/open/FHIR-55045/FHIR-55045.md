- **Description**: The Ingredient references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: ingredient-role (IngredientRole) referenced by ValueSet ingredient-role bound to element Ingredient.role; CodeSystem: ingredient-function (IngredientFunction) referenced by ValueSet ingredient-function bound to element Ingredient.function;
