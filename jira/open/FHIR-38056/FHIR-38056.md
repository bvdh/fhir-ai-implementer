- **Description**: DeviceDefinition.classification.type uses the DeviceType valueset. This valueset does not describe a classification or risk class (e.g. FDA medical device class I, EU MDR class IIb). A different example valueset should be used.

If a valueset can be identified (or created) that does cover safety/risk class, consider strengthening binding to extensible.
