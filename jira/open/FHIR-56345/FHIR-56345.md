- **Resolution Description**: Propose to support calibration information of a device by defining an extension applicable to the Device resource with the same attributes as calibration in the DeviceMetric.
- **Change Category**: Enhancement
- **Change Impact**: Compatible, substantive
- **Description**: The DeviceMetric has a backbone element to represent available calibration information. This element is missing from the Device resource, but would be useful there as well.

In the IEEE 11073 PoCD specifications calibration information can be present at metric, channel, VMD and MDS level. Ideally HL7 FHIR supports this as well. See FHIR-51356.

For FHIR R4 the PoCD IG will use an extension to cover this.

Possible solutions for FHIR R6 include:

add calibration element to the DeviceResource
define a (core) extension for calibration information that can be applied to Device
move calibration from DeviceMetric into an extension that can be used for Device and DeviceMetric

Calibration seems an important enough topic to cover in FHIR Core or the (core) extension package.
