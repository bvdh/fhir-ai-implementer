- **Description**: The implementation notes state:

The _content search parameter shall search across the DocumentReference.content.attachment.data, and DocumentReference.content.attachment.url.

This guidance is wrong. The FHIR specification is not specifying search parameters that include information form other resources than its own.

The content definition _(https://build.fhir.org/search.html#_content) explicitly states that its needs to be restricted to the resource type the search is on.

Please remove the comment or replace it with guidance why it does not include the referenced resource.
