- **Description**: 1. Change "All primitive data types have a value and also extensions. Even if the element is present, the value might not be present; instead, an extension may be present the either provides information about why the value is not present, or provides an expression that might be used to generate a value in a particular context."

to

"All primitive data types permit a value property and an extension property. A primitive can be populated with just a value, no value and one or more extensions, or both a value and extensions. If no value is present, at least one extension must be present. Extensions in place of a value might provide information about why the value is not present, provide an alternate expression of the value, or provide an expression that can be used to generate a value in a particular context. Alternate values might be free text instead of numbers or dates, values missing required elements, such as a time with no time zone, or an alternate expression such as a Hijri date in place of a Gregorian date"

2. In the datatypes page section on 'primitives', include a link to this section in ElementDefinition.

3. Update the originalText extension to note that it can accompany a value or components, but can also be sent in place of a primitive value or components
