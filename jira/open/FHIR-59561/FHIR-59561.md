# FHIR-59561: CanonicalResource refers to Resource.meta.versionId by the wrong element name .version instead

- **Description**: In the CanonicalResource the line reads: The difference between the CanonicalResource version (business version) and the Resource version in .meta.version is discussed on Resource.

But the element name is versionId so it should read: .meta.versionId

The wrong element name also appears in a comment on CanonicalResource.version: https://build.fhir.org/canonicalresource-definitions.html#CanonicalResource.version

Where it says: "Resource.meta.version" which instead be "Resource.meta.versionId"

Even though the CanonicalResource template/pattern is used for other Resources, that comment issue isn't copied over to them.
