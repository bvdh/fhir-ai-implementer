- **Resolution Description**: Remove the previously added handle-unclosed-expansion parameter.

Replace the paragraph:

When a server cannot correctly expand a value set because it does not fully understand the code systems (e.g. it has the wrong version, or incomplete definitions) then it SHALL return an error. Clients SHOULD be able to handle incomplete or unclosed value set expansions, and can indicate when they do with the handle-unclosed-expansion parameter. Servers return such ValueSet resources for a variety of reasons (e.g. fragment, post-coordinated concepts, code systems with a grammar, size, etc.). If handle-unclosed-expansion is true, servers SHALL indicate incomplete or unclosed value set expansions using the ValueSet Unclosed extension. If handle-unclosed-expansion is false, servers SHALL return an error if the value set is incomplete or unbounded.

with:

When a server cannot correctly expand a value set because it does not fully understand the code systems (e.g. it has the wrong version, or incomplete definitions) then it SHALL return an error.

Add a new paragraph after the paragraph above:

Servers SHOULD indicate incomplete or unclosed value set expansions using the http://hl7.org/fhir/StructureDefinition/valueset-unclosed . Servers return such ValueSet resources for a variety of reasons (e.g., fragment, post-coordinated concepts, code systems with a grammar, size). If Clients receive unclosed expansions (asserted with the above extension) they SHOULD be aware of the extension and not assume the expansion is complete.
- **Resolution Vote**: Grahame Grieve/Bryn Rhodes : 4-0-1
- **Vote Date**: 2026-10-12
- **Change Category**: Clarification
- **Change Impact**: Compatible, substantive
- **Description**: The value set extension http://hl7.org/fhir/StructureDefinition/valueset-unclosed specifies that it is only returned to the client if the client specifically indicates that it handles the extension correctly.

Which means that we need to define a parameter for doing that. I propose

handle-unclosed-expansions: boolean which has a default value of false
