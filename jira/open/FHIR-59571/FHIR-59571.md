- **Description**: For Goal: https://build.fhir.org/goal.html#scope
It says "A goal of a plan for a condition such as a diabetes might specify"
Should be "A goal of a plan for a condition such as diabetes might specify"

For AdverseEvent: https://build.fhir.org/adverseevent.html#scope
It says "that is detected prior implantation"
It should be "that is detected prior to implantation"

For Procedure.occurrence[x]: https://build.fhir.org/procedure-definitions.html#Procedure.occurrence_x_

It says "look at the occurence element"

"occurrence" is spelt wrong, it should have two r's.

And this should probably should be passed to FHIR-I or some other work group because I see 40 other files with that same "occurence" misspelling. They should be fixed in batch all at once. EXCEPT FOR the fhir.ini file, that should be skipped since it's correcting a misspelling it looks like.
