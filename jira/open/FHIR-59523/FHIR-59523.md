- **Resolution Description**: Add to the strength[x] comment:

use the CodeableConcept only when there is no amount (qs, trace);
for "q.s. ad", use a Quantity, or the numerator of a Ratio, with comparator = ad.
Optionally, add a compounded example: hydrocortisone 1 g in cream base ad 100 g.
Leave the value set and the binding unchanged, since FHIR-55332 covers those.
- **Description**: The spec never says when to use the CodeableConcept and when to use a Quantity or Ratio.
For magistral preparations, "q.s." on its own fits the code qs. "q.s. ad 100 g" needs the target amount, which a code can't carry.
FHIR has supported this since R5, with Quantity.comparator = ad, but the Medication spec doesn't mention it. Without guidance, implementers may use qs and lose the amount.
This is compatible with the decision to move the value set to THO.
