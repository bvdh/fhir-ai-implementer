# FHIR-56283: Code system properties should be in THO

## Metadata

- **Summary**: Code system properties should be in THO
- **Created**: 2026-04-03
- **Updated**: 2026-10-06
- **Resolved**: 2026-04-20
- **Status**: Resolved - change required
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Lloyd McKenzie
- **Resolution**: Persuasive with Modification
- **Issue Links**: Relates
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R5
- **Work Group**: Terminology Infrastructure
- **Related Artifact(s)**: CodeSystem
- **Resolution Description**: Remove code system properties code system from the FHIR core specification.

Once the related UP ticket is resolved, update the core specification to point to THO. The URI will be retained in THO.

A statement to say that these are the codes available at the time of the publication of the core spec and that additional properties can be found in the code system (and point to THO).
- **Resolution Vote**: Lloyd McKenzie / Grahame Grieve : 16-0-0
- **Vote Date**: 2026-05-20
- **Change Category**: Correction
- **Change Impact**: Non-substantive
- **Description**: https://build.fhir.org/codesystem.html#defined-props does not meet the criteria for living in core, and it's the sort of thing that is appropriate to evolve between FHIR releases. We'd want to keep the URL the same for the move though.
