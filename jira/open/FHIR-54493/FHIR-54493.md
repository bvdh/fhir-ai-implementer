- **Description**: The EncounterHistory resource was removed from the FHIR core spec and put in to the AdditionalResource Administrative Incubator.
However, the language of the narrative in 8.11.1.1 still sounds like if it is still in the spec.

Therefore, the proposal is to:

Add some information that EncounterHistory is not a Resource of the FHIR core spec yet but is part of the Administrative Incubator and might be integrated to the core spec at a later point in time
Consider removing the note to implementers about it since it just contains information about the changes between R4 and R5
