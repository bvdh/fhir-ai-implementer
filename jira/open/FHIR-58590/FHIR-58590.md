- **Resolution Description**: Change the type of DosageSafety.doseLimit.value[x] from integer to positiveInt (valuePositiveInt): the integer is a quantity or number of doses, and a limit of zero or less has no meaning.
Add an invariant on DosageSafety.doseLimit for the Quantity choice: "If value is a Quantity, it SHALL be greater than zero" (value.ofType(Quantity).exists() implies value.ofType(Quantity).value > 0).
- **Description**: DosageSafety.doseLimit.value[x] allows integer as a datatype. Because this element represents a "Quantity that is safe to use," a negative integer does not appear to have a meaningful interpretation. Consider either using positiveInt if zero is also not a valid dose limit, or adding an invariant requiring the integer value to be non-negative if zero is a valid value.
