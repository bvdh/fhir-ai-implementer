### 2. Kwangmo Yang - 2026-02-07

Thank you for the reference to the Dragon project and the FHIR-to-CDISC mapping IGs.

I am aware that these IGs provide mapping strategies for clinical research. However, the core of my request is not about the downstream mapping process, but rather the semantic ambiguity within the Core R6 specification itself.

Current observations suggest:

Mapping guides (like Dragon) function as a post-processing step; they do not resolve foundational ambiguity in the source data.

Without explicit wording in the Core Spec to distinguish AI-generated predictions from actual observed events, we risk inconsistent data generation at the source.

This inconsistency will ultimately compromise the integrity of any derived profiles or subsequent CDISC mappings.

I believe ensuring clarity at the Core level is a prerequisite for reliable interoperability, regardless of the specific IG used. I look forward to your thoughts on how the Core R6 spec can better support this distinction.

### 5. Kwangmo Yang - 2026-01-29

Thank you for the feedback. To make this ticket more actionable, I would like to clarify that my request stems from a practical implementation perspective within a large-scale clinical environment.

Specifically, regarding the AdverseEvent resource in R6, I find the guidance in the "Boundaries and Relationships" section to be insufficient for ensuring consistent derived profiles across different jurisdictions.

The core issue is:

1. There is a lack of explicit wording on how the Core specification governs the constraints of derived profiles when dealing with AI-generated adverse event predictions versus actual observed events.

2. Without a clearer definition of these boundaries in the Core R6 spec, we risk significant fragmentation where local Implementation Guides (IGs) interpret the "intended use" of core elements (like actuality or occurrence) differently.

I am seeking a more rigorous description of these relationships within the specification to prevent such interoperability gaps during the early adoption phase of R6.
