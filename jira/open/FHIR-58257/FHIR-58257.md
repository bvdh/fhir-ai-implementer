- **Description**: Multiple Resources in the FHIR specification have been moved out and became Additional Resources defined in Incubator IGs as part of the move to the current normative R6 ballot.

There is a need to explain in the simplest terms possible how to reference these Additional Resources from FHIR-defined Resources and that explanation and method needs to be in the R6 specification so it does not change from IG to IG, or vary across the Additional Resource types.

In addition, any Resource defined in the core specification with a constraint limiting resource type choices for a given Reference datatype in the StructureDefinition must be allowed to reference an Additional Resource without breaking validation rules. For example, ResearchStudy.result used to have Citation as a type option for referencing results of a research study. This will need to be supported with a reference to the Additional Resource now named PublicationRecord, but doing so should not lead to a validation error because of the type limitation in R6 specification.
