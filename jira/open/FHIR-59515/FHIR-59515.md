The RDF page does not explain that RDF Turtle can serialize multiple FHIR resources separately in the same document. This should be clarified so that the rest of the page makes sense. Additionally, since contained resources "cannot be queried or manipulated independently" in the context of a conformant REST API, a link should be added to that section.

See https://github.com/w3c-cg/hcls-fhir-rdf/issues/239#issuecomment-5708202682
