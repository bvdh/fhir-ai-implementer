- **Description**: FMG would like MnM to develop options (and criteria for deciding between them) to handle situations where normative resources encounter situations that would ideally result in breaking changes. For example, if an element was 0..1 and now needs to repeat, might add a new parallel element, deprecate the existing element and add a new one, use an extension, create a 'grouping' resource and reference that instead, etc.
