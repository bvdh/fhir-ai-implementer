- **Description**: Make the following clarifications to the Restricted Subset section:

"This page documents a restricted subset of the" - is it really meant to be this page, or this section?
Include that the only child elements are permitted (recursively), along with indexers (e.g. [0]) where appropriate
Append to the operation outcome usage a note that this usage further constrains the language to prevent use of ANY functions - only child properties (element names) and indexers (recursively).
The DataRequirement.dateFilter seems to restrict tighter than just the simple subset - intentional? (missing ofType and extension)
Include a note that other implementation guides MAY also use the restricted Simple subset too
Include several useful examples:

Patient.birthDate
Patient.name[0].family
Patient.name[2].given[1]
QuestionnaireResponse.item[0].item[2].answer[0].value
