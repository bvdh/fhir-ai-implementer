- **Description**: Following up on the resolution to http://jira.hl7.org/browse/FHIR-53619:

"Agreed, the definition of method is that it is specific to the algorithm or method used to generate the risk assessment, whereas the code is the type, or classification of the risk assessment."

I would like to point out that the cardinality for RiskAssessment.code of 0..1 does NOT allow to have BOTH a category AND a type of RiskAssesmenton an instance. Due to the lack of any additional Element "category" there is no way to have BOTH a category e.g. "Medication-related risks" AND a specific type "medication-interaction" or "medication-contraindication" in an instance.

I suggest to either introduce an additional .category element OR relax the cardinality of .code to 0..*
