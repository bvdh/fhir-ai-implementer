- **Description**: Returning 'no body' is unlikely to ever be correct in the context of bundle processing. The http code alone is not enough, and there is no defined mechanism to follow-up and get more information (e.g., something that could be in the location header).

Assuming Gino's reading of the RFC is correct, returning the bundle with the minimal amount of data for each of the individual requests should be allowed under prefer: return=minimal

Let's clarify this in the spec.
