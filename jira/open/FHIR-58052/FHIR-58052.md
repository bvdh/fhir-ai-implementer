# FHIR-58052: Clarify the resources that are expected to be included in a Document Bundle

- **Related Section(s)**: 3.4.1
- **Description**: Please clarify the following sentence:

"

The document bundle SHALL include only:

The composition set: the root Composition resource, and the resources it links to
The supporting information: Any resources that are part of the graph of resources that reference or are referenced from the composition set, either directly or indirectly (e.g., recursively in a chain)

"

That rule will make a huge number of possible non-relevant resources be included in the Bundle. Or is the expectation that those resources SHOULD be included if they are deemed relevant for the author?
