- **Description**: An example of a search on Patient is given. The page proceeds with the following example assert:
Verify that the search operation returned the right resource type:{}

<action>

<assert>

<resource value="Patient"></resource>

</assert>

</action>
It seems to me that the right resource type returned for a search would be Bundle (containing 0..* Patient resources).

The two following examples (containing `path` and `compareToSourcePath` elements which are to be deprecated in R6) also ignore that the Patient resource should be returned inside of a Bundle.
