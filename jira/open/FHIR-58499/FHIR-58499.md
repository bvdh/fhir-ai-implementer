- **Resolution Description**: Add to the comment on Dosage.asNeededFor: "If there is more than one asNeededFor, the medication can be taken when any of them applies. When several conditions must apply together, use a single code that expresses the combination."
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: Dosage.asNeededFor has cardinality 0..*, but the specification does not clearly define the logical relationship between multiple entries.

The assumed interpretation is that multiple asNeededFor conditions are combined using logical OR, while an AND combination would need to be represented using a pre-coordinated concept.

Please clarify the intended semantics of multiple asNeededFor entries explicitly in the specification, including how AND combinations should be represented.
