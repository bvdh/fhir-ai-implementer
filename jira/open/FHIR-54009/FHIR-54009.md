- **Grouping**: Binding
- **Description**: In the guidance for required binding strength 4.1.4.2.1 it is noted that "Required binding strength SHALL be used for elements with type code (unless the element has a context-free (i.e., no binding.additional.usage present) additional binding with purpose = maximum , a combination which is strongly discouraged as of R6)". However, as of FHIR-46350 the maximum binding strength has been deprecated in favor of required. Although this is a discouraged combination, it would make sense to use a non-deprecated binding.

Additionally, after that it is noted "Exceptions to this rule need to be approved by the FHIR-I work group which will document the patterns that qualify as exceptions." It would be helpful for those exceptions to be linked here.
