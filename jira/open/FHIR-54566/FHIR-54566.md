- **Resolution Description**: The scope of a "no known medications" statement is given only by its code. Other elements give the context of the statement but do not narrow it. We will add a section "Statements of no known medications" to the MedicationStatement notes, following the "Negated Allergies and Intolerances" section of AllergyIntolerance:

Statements of no known medications

When `MedicationStatement.medication` contains a code that expresses a situation rather than a medication, such as SNOMED CT 787481004 |No known medications|, the scope of the statement is given only by that code. A general code means that no medications at all are known to be taken. A more specific code, for example one stating that no medications of a particular class are known, limits the statement to that class. National editions of SNOMED CT may provide more specific codes.

`subject`, `effective[x]`, `dateAsserted`, `informationSource`, `author`, `encounter` and `note` give the context of the statement as usual. `effective[x]` is the time or period for which it is asserted that no medications are known to be taken.
`dosage`, `adherence` and `reason` describe the use of a medication and SHOULD NOT be populated. If they are present, receivers SHALL NOT interpret them as narrowing the statement.
`category` can be used to classify the statement (for example, community or inpatient), but it does not narrow the statement. To make a narrower statement, use a more specific code.

Statements about medications should be reconciled with any "no known medications" statement. For example, when a medication is recorded, a "no known medications" statement for the same period should be marked entered-in-error, or removed from the medication list.

This is guidance only: no invariant is added, because the binding of `medication` is an example binding.
- **Description**: Clarify how the use of a "no known medications" code interacts with other elements in the resource. Do those other elements qualify the "no known medications" statement?

For example,

Does "no known medications" with a category specified mean no known medications in the context of that specific category (but there may be medications in the context of other categories)?
Does "no known medications" with specific "dosage" specified mean no known medications taken as specified by the dosage instructions (e.g., "no known oral medications", "no known daily medications", etc?
How would one interpret "no known medications" with adherence code specified as "not-taken"? There are no known medications that are not being taken?

Or does the semantic or implied meaning of the "no known medications" code potentially override any other qualifiers (in which case such qualifiers should be disallowed)?

Perhaps the specification cannot (or should not) explore every possible combination, but it would be beneficial to say something about how the other elements interact (or not) with medication codes that specify a situation rather than a medication.

### 3. Stephen Chu - 2026-04-07

MedicationStatement.medcation = 787481004 | No known medications --> ins intended to be a global, positive assertion that to the best knowledge of the asserter | statement author, no information about a patient's medication is known to the asserter | author.

As this is intended to be a global, positive assertion:
Q1 - Does "no known medications" with a category specified mean no known medications in the context of that specific category (but there may be medications in the context of other categories)?
*Comment *- it may represent a global statement about all categories (i.e. care settings: inpatient | outpatient | community | discharge).
MedicationStatement.category has cardinality defined to be 0..* --> it does not preclude all category values to be included in a statement
In case if any of the category values are included, it should be use case or clinical scenario specific. For example, in a hospital discharge summary, MedicationStatement.category value may be set to "inpatient" - in such use case, the "no known medication" assertion will only be limited to "no known inpatient medication at the time of discharge" and other interpretation should be inferred or taken

Q2 - Does "no known medications" with specific "dosage" specified mean no known medications taken as specified by the dosage instructions (e.g., "no known oral medications", "no known daily medications", etc?
Comment - in the context of a global, positive assertion of no known medication, it is anticipated that clinical common practice will not populate MedicationStatement.dosage, MedicationStatement.adherence, MedicationStatement.reason
Even if MedicationStatement.medication = no know class of medications, e.g. no known ACE Inhibitor, no known anticoagulant, it is expected that these would not be populated: MedicationStatement.dosage, MedicationStatement.adherence, MedicationStatement.reason
If a no know medication statement is about a specific medication, for example MedicationStatement.medication = "no known fluoxetine", clinical logic would lead to the outcome that there will be no need to populate MedicationStatement.dosage, MedicationStatement.adherence, MedicationStatement.reason

Q3 - How would one interpret "no known medications" with adherence code specified as "not-taken"? There are no known medications that are not being taken?
Comment - if no information is known about patient's medication, it is unlikely that there is information about adherence.

These questions raise a key requirement - that clear implementation guidance information on the use of "no known medication" is required
