- **Resolution Description**: Technical correction to the "Structure" lists in source/dosage-examples.html (the example instances are not changed) and to one comment in DeviceDispense.

Example 1

Replace MedicationRequest.dosageInstruction.renderedDosageInstruction with MedicationRequest.dosageInstruction.renderedInstruction.
Replace "…doseAndRate[0].doseQuantity = 1 tablet (or explicit mg if desired)" with "…doseAndRate[0].doseQuantity = 2.5 mg (1 tablet)".

Example 2

Replace Dosage.asNeededBoolean with Dosage.asNeeded.
Remove the item "Dosage.maxDosePerPeriod (Ratio) for 150 mg per week". The following item (MedicationRequest.dosageInstruction.safety.doseLimit, scope period, for 150 mg per week) stays.

DeviceDispense

Remove the comment on DeviceDispense.usageInstruction, because it refers to elements that DeviceDispense does not have. The short ("Full representation of the usage instructions") and the definition stay.
- **Description**: Each example on the Dosage examples page has a "Structure" list naming the elements used. In Examples 1 and 2, these lists still use element names from before the Dosage restructure (FHIR-51540) or from R4. They also do not match the YAML, JSON and XML views of the same example.

Example 1

"MedicationRequest.dosageInstruction.renderedDosageInstruction = "1 tablet per day for 3 months"": there is no renderedDosageInstruction element. The rendered text is DosageDetails.renderedInstruction, and the YAML, JSON and XML views of the example use renderedInstruction. (The MedicationRequest, MedicationDispense and MedicationStatement pages already note that renderedDosageInstruction moved to DosageDetails.renderedInstruction.)
"…doseAndRate[0].doseQuantity = 1 tablet (or explicit mg if desired)": the example itself uses doseQuantity 2.5 mg, since the correction in FHIR-54523.

Example 2

"Dosage.asNeededBoolean for PRN (evening)": asNeededBoolean is the R4 choice-type name. Since R5 the element is Dosage.asNeeded (boolean), with the reason in Dosage.asNeededFor. The JSON and XML of the example use asNeeded.
"Dosage.maxDosePerPeriod (Ratio) for 150 mg per week": maxDosePerPeriod no longer exists. It was replaced by DosageSafety.doseLimit with scope period when FHIR-51540 was applied, and the next item in the same list already describes the safety.doseLimit form, which is what the example uses.

DeviceDispense

The comment on DeviceDispense.usageInstruction reads "The content of the renderedDosageInstructions must not be different than the dose represented in the dosageInstruction content." DeviceDispense has neither renderedDosageInstructions nor dosageInstruction. The comment appears to have been copied from MedicationDispense.

This is the same kind of inconsistency between text and structure that FHIR-54523 corrected in the example instances.
