- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: FHIR Infrastructure
- **Related Page(s)**: UsageContext (see Metadata Types) [deprecated]
- **Description**: Allow a date or other temporal datatype as a value for UsageContext.value[x].

UsageContext is used to describe the context in which an artifact is intended to be used or is applicable. However, UsageContext.value[x] currently does not support a date or other temporal datatype.

This makes it impossible to represent a usage context that is defined by a specific date or temporal period. For example, a Composition may need to express that it is applicable to, or intended for use in, the context of a particular date. The addition of canonical<ValueSet> (see ticket https://jira.hl7.org/browse/FHIR-45467) addresses the case where the possible contextual values are a set of codes, but it does not address contexts defined by a date or time period. Add an appropriate temporal datatype to UsageContext.value[x]. At minimum, this could be date; It may also be worth considering whether the more general solution should support: date dateTime Period
