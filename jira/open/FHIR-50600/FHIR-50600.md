- **Resolution Description**: We will adjust this paragraph

"If you have a highly structured report, then use DiagnosticReport - it has data and workflow support. Details about the request for a diagnostic investigation are captured in the various "request" resources (e.g., the ServiceRequest) and allow the report to connect to clinical workflows. For more narrative driven reports with less work flow (histology/mortuary, etc.), the Composition resource would be more appropriate."

to read:

DiagnosticReport provides a detailed information model for reports on data produced by diagnostic investigations (e.g., laboratory, imaging, and anatomic pathology reports) and supports the relevant workflow and data needs. Details about the request for the diagnostic investigation are captured in the various "request" resources (e.g., the ServiceRequest) and allow the report to connect to clinical workflows.

If additional styling of the DiagnosticReport is needed (e.g., sections), then use DiagnosticReport.composition to leverage the presentation functions of the Composition resource to capture that additional styling.

For clinical documents where the detailed information model and workflow of the DiagnosticReport resource do not apply, the Composition resource can be used alone instead of the DiagnosticReport resource.
