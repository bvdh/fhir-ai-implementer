- **Description**: The type of Reference.reference is defined as string, but in all cases it must be some kind of URI. However, this constraint is not yet defined in an invariant, nor is it entirely clear in the description. This lack of an invariant is currently permitting erroneous examples to go undetected: this example contains a vertical bar in a Reference.reference, though vertical bar is never allowed in a URI, per RFC 3986. (It should have been percent-encoded as %7C.

Two things are needed:

An invariant should be added for Reference.reference
The description of literal reference should be clarified to explicitly state that it is always a URI.
