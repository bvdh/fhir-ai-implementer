- **Description**: For the create interaction, common HTTP status codes are listed under the phrase "Common HTTP Status codes returned (in addition to normal HTTP errors related to security, header and content type negotiation issues):"

HTTP 303 (See Other) could also be listed here, as the guidance for the update interaction that

"Servers that determine that a POST would result in a duplicate MAY return a 303 See Other pointing to the existing (unchanged) record and indicating that the record was not created because the specified resource already exists at the specified location"

may apply to both the create and the update interaction.
