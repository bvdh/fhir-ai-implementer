- **Description**: Affected elements:

`TestScript.setup.action.assert.defaultManualCompletion`
`TestScript.setup.action.assert.operator` with value `manualEval`

The `manualEval` operator requires execution to pause so that an outcome of `pass`, `fail`, `skip` or `stop` can be provided.

`defaultManualCompletion` defines a default outcome “if one of the enumerated values is not applied”. Its meaning when missing states that the default outcome is `skip`.

It is unclear when this default is applied. If a `manualEval` assertion always pauses until an outcome is provided, there appears to be no point at which no enumerated value is applied. It is also unclear whether specifying `defaultManualCompletion` implicitly makes the assertion a manual assertion when `operator` is absent.

Please clarify that `defaultManualCompletion` is only applicable to a `manualEval` assertion.

Please also define the concrete circumstances that can cause the default to be applied. For example, only when a manual evaluation times out after some time?

If there is no supported circumstance in which `manualEval` can conclude without an explicit outcome, please consider removing `defaultManualCompletion`.
