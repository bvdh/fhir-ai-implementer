# FHIR-57810: Timing datatype is wrongly shown as Element instead of BackboneType

## Metadata

- **Summary**: Timing datatype is wrongly shown as Element instead of BackboneType
- **Created**: 2026-07-06
- **Updated**: 2026-07-06
- **Status**: Submitted
- **Project**: FHIR Specification Feedback
- **Type**: Technical Correction
- **Reporter**: David Booth
- **Resolution**: Unresolved
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: FHIR Infrastructure
- **Related URL**: https://build.fhir.org/datatypes.html#Timing
- **Related Page(s)**: Datatypes
- **Related Section(s)**: Structure tab
- **Description**: This was partially fixed in https://jira.hl7.org/browse/FHIR-17108 , but some spots were missed.

The "General-Purpose Datatypes" diagram correctly shows the type of Timing as BackboneType: https://build.fhir.org/datatypes.html#2.1.30.0

But its type is incorrectly shown as Element in the "Structure", "XML", "JSON", "Turtle", and "All" tabs of the datatypes Timing section: https://build.fhir.org/datatypes.html#timing
The inherited property "modifierExtension" should also be listed in those spots.
