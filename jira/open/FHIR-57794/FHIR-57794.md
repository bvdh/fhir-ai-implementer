# FHIR-57794: Move measure.subject and measurereport.subject to the group

## Metadata

- **Summary**: Move measure.subject and measurereport.subject to the group
- **Created**: 2026-07-01
- **Updated**: 2026-09-22
- **Resolved**: 2026-09-22
- **Status**: Resolved - change required
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Bryn Rhodes
- **Resolution**: Not Persuasive with Modification
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Clinical Quality Information
- **Related URL**: https://build.fhir.org/measure.html
- **Related Artifact(s)**: MeasureMeasureReport
- **Resolution Description**: 1. Undeprecate subject at the root, as it is required to evaluate supplemental data criteria specified at the root
2. Add subject to population, the same as it is specified on group, to allow for measures that may have different subjects in different populations (e.g. a ratio measure that counts events (patient-based) per estimated number of events by facility (location-based)
3. Update all examples and documentation relative to determining subject that it can vary per group, and update the CAUTI example to specify Location as the subject of the denominator.
4. Add "rate" and "performanceRate" as aliases of "group" in both Measure and MeasureReport.
- **Resolution Vote**: Matt Tiller/Anne Smith: 24-0-0
- **Vote Date**: 2026-09-22
- **Change Category**: Enhancement
- **Change Impact**: Non-compatible
- **Description**: In the last ballot of R6, all the calculation elements except subject were removed from the root, in favor of specifying them exclusively on all groups.

However, subject should be removed from the root as well, in line with the same decision for all the other calculation elements.

- **Jira**: https://jira.hl7.org/browse/FHIR-57794

## Comments

### 1. Bryn Rhodes - 2026-09-22

Although it should be possible to specify the subject for each group (and potentially even for each criteria in the case of ratio measures), the subject must still be specified at the root because without it, we would not be able to evaluate supplemental data criteria specified at the root of the measure.
