- **Description**: This change requests proposes adding the following additional elements to the TerminologyCapabilities resource types to allow servers to provide human-readable descriptions for how they support a particular code system in general, and for specific versions.

TerminologyCapabilities.codeSystem.description: A natural-language description about how the code system is supported by the terminology server that applies to all versions.

TerminologyCapabilities.codeSystem.verson.description: A natural-language description about how the specific version of the code system is supported by the terminology server.

Both description elements will be defined with the following structure:

Name: description
Type: element
Cardinality: 0..* (to support multiple languages)
Summary: false
Subelements

Subelement 1: language

Type: code
Cardinality: 1..1
Binding: ValueSet http://hl7.org/fhir/ValueSet/languages

Subelement 2: value

Type: Markdown
Cardinality: 1..1

Examples of the kinds of information that can be provided in this element include:

Support for hierarchy, properties and filters,
Support for particular terminology operations.
Support for implicit value sets.
Support for aspects of the Using X with HL7 Standards pages from THO.
Known issues.
