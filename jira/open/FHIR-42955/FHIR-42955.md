- **Description**: Incorrectly defined code system supplements can potentially cause significant issues in the use of the underlying code system. For example:

Adding invalid designations
Adding properties which create invalid parent/child relationships
Adding properties to create invalid alternate codes

To minimise the possibility of this occurring, it is suggested that guidance be added to the section on supplements which advises implements on the safe use of supplements and the implications of its use.
