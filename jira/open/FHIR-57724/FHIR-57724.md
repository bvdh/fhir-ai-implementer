- **Description**: Immediately after the bulleted list at the top of the page is a sentence/paragraph in a different font. It appear that that sentence should link to something, but it doesn't.

Correct the link. Correct the font.

The bundle SHALL NOT include resources that are not part of a connected graph of RESTful references (i.e., using Reference.reference, canonical or a URI) that includes the MessageHeader; I.e. It must be possible to traverse the references between resources in such a way that all resources are linked. See Graph-connected Bundles for further details.

All message Bundles SHALL be a [fully-interconnected graph](link to above).

The MessageHeader resource has a code - the message event - that identifies the nature of the request message, and it also carries additional request metadata. The other resources in the bundle depend on the type of the request.
