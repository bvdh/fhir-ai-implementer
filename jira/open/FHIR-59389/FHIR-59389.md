# FHIR-59389: EpisodeOfCare.manager should allow for a RelatedPerson

## Metadata

- **Summary**: EpisodeOfCare.manager should allow for a RelatedPerson

- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Grahame Grieve
- **Resolution**: Unresolved
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Patient Administration
- **Related Artifact(s)**: EpisodeOfCare
- **Description**: EpisodeOfCare is defined as

> An association between a patient and an organization / healthcare provider(s) during which time encounters may occur. The managing organization assumes a level of responsibility for the patient during this time.

It's not particularly clear here what the scope of 'organization / healthcare provider' is - but practically, the definition of the resource makes clear that an institution is intended. This makes EpisodeOfCare difficult to use in a social/home care setting problematic.

Please allow the careManager to be a RelatedPerson: the patient's designated carer. Further, please clarify the intent here: is this intended to be confined to institutional care? if it is, do we need to define a different resource for the same purpose outside institutions?
