- **Description**: Patient Care voted to change AllergyIntolerance.category from code to CodeableConcept (FHIR-55647 Change AlllergyIntolerance.category binding - Jira)

As a result, FHIR-I might want to revisit the examples related to AllergyIntolerance.category

GET [base]/AllergyIntolerance?category=medication&category=biologic
GET [base]/AllergyIntolerance?category=medication,biologic

The examples aren't wrong, but now that the binding and data type have changed, it might be preferred to include the code system in the search examples
