Specimen.processing.performer
BiologicallyDerivedProduct.collection.collector and {}BiologicallyDerivedProductDispenseperformer.actor do not allow for an AI to take any of these actions, because Device is not a target.

It's not clear to me whether this is relevant - OO should review whether an AI can do any of these things. I suspect that an AI, or an a robotics machine, can be a Specimen.processing.performer

Note about AI participations: the question is not whether we would like an AI to do this, or think that it's good practice. The question is: is it impossible for an AI to do this? if it's not, then Device should be one of the possibilities. Note that the participant pattern includes Device (partly for this reason), so not allowing it is also a deviation from the workflow pattern anyway.
