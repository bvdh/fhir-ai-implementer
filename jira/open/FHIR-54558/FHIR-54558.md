- **Resolution Description**: Existing text:

The meaning of the Coding is defined by the code. The system provides the source of the definition of the code, along with an optional version reference. The display is a human display for the text defined by the system - it is not intended for computation.

Change to:

The Coding type allows a specific code from a code system to be identified by providing the code system identifier, the `code`, and an optional `version`. In addition, the `display` element allows a natural language representation of the code to be provided - it is not intended for computation. The `user selected` element allows applications to capture whether or not users selected codes in context.
