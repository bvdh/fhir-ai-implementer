- **Description**: The ManufacturedItemDefinition references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: manufactured-dose-form (ManufacturedDoseForm) referenced by ValueSet manufactured-dose-form bound to element ManufacturedItemDefinition.manufacturedDoseForm; CodeSystem: unit-of-presentation (UnitOfPresentation) referenced by ValueSet unit-of-presentation bound to element ManufacturedItemDefinition.unitOfPresentation;
