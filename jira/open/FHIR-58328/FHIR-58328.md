- **Description**: Composition.subject went from 0..1 in R4 to 0.. in R6, but the multiple-subject guidance doesn't explain when repetition should actually be used.* R6 says Composition can have multiple subject references, yet §2.8.7 says that where different sections are about multiple distinct subjects, Composition.subject should be omitted and section-subject used instead.

Add guidance for when mulitple Composition.subjects would exit and create an example composition of a legitimate use case. Perhaps the example might represent the text example in the definition "a set of patients that share a common exposure"

For example:

Multiple Composition.subject references are appropriate when the Composition as a whole is collectively about all listed subjects. When individual sections have distinct subjects, use the section-level mechanism.
