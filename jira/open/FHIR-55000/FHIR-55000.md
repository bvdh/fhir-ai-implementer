- **Description**: BDP.productCode can/should point to ISBT 128 product description codes (https://www.isbt128.org/uri/productdescriptioncode/) as example or extensible bindings. BDP.property.type should point to ISBT 128 data elements (https://www.isbt128.org/uri/) as example or extensible bindings. These changes were voted upon and approved for terminology but never made it into the build.
