- **Description**: A few suggest updates to the content in this section:

There are many references to 'HL7' which, for avoidance of doubt, should be changed to 'HL7 International'.
The first bullet point which currently states "Additional Resources to be used like this SHALL be registered with HL7" should be amended to state "Additional Resources to be used like this SHALL be registered with and approved for use by HL7 International". That then supports the next bullet point which refers to 'approval'.
The placeholder text in "HL7 publishes the list of approved resource at (somewhere?) (todo: this needs further work" must be updated with the correct information.
The placeholder text in "The FHIR Management Group (FMG) needs to approve moving into core (criteria TBD by FMG)." must be updated with the correction information.
