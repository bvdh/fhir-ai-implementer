- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: The description for not-applicable is

There is no proper value for this element (e.g. last menstrual period for a male).

Suggest replacing the e.g. with a non-gendered example that demonstrates what we mean by "proper".

Something like: Occupation for an infant
