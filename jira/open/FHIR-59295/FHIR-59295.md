# FHIR-59295: FamilyMemberHistory should allow for AI as a recorder

## Metadata

- **Summary**: FamilyMemberHistory should allow for AI as a recorder
- **Created**: 2026-09-20
- **Updated**: 2026-09-21
- **Status**: Submitted
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Grahame Grieve
- **Resolution**: Unresolved
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Patient Care
- **Related Artifact(s)**: FamilyMemberHistory
- **Description**: FamilyMemberHistory recorder does not allow Device as a target, so an AI cannot be a recorder of a FamilyMemberHistory.

Note about AI participations: the question is not whether we would like an AI to do this, or think that it's good practice. The question is: is it impossible for an AI to do this? if it's not, then Device should be one of the possibilities. Note that the participant pattern includes Device (partly for this reason), so not allowing it is also a deviation from the workflow pattern anyway.
