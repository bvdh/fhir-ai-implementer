- **Description**: ArtifactAssessment.workflowStatus has a "entered-in-error" code in the list of codes, and I see for a few other resources that have a "status" or "lifecycleStatus" element with a "entered-in-error" code those elements also have an Is Modifier attached to it that says "true (Reason: This element is labelled as a modifier because it is a status element that contains status entered-in-error which means that the resource should not be treated as valid)" and a comment like "This element is labeled as a modifier because the lifecycleStatus contains codes that mark the resource as not currently valid. It would be unusual for a recorder of a goal to not know this value; it is included to support legacy data and is strongly discouraged."

Other examples of status "entered-in-error" with Is Modifier:

Goal.lifecycleStatus
Communication.status
Observation.status
