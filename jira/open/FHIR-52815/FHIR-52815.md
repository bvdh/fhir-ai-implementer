- **Resolution Description**: Move the data, static, and narrative canonicalization formats from the core spec into the API Incubator IG.
Rename the document canonicalization format to bundle.
Update the description to:
The Bundle.id and Bundle.meta elements on the root Bundle are omitted prior to signing. This allows for a bundle to be copied from server to server.
Add a reference to the canonicalization formats in the API Incubator to the existing section.
In the API Incubator add static-labeled as a new canonicalization format, with the description:

The elements of type Narrative (e.g. Resource.text, Composition.section.text, etc.), Resource.id, Resource.meta.versionId, and Resource.meta.lastUpdated are omitted prior to signing.
- **Description**: Suggest that for http://hl7.org/fhir/canonicalization/
{fmt}
#static, only remove resource.id and resource.meta.versionid and resource.meta.lastupdate, since the other part in meta such as security tags can be useful.
