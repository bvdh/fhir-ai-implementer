- **Description**: The PackagedProductDefinition references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: package-type (PackageType) referenced by ValueSet package-type bound to element PackagedProductDefinition.type; CodeSystem: legal-status-of-supply (LegalStatusOfSupply) referenced by ValueSet legal-status-of-supply bound to element PackagedProductDefinition.legalStatusOfSupply.code; CodeSystem: packaging-type (PackagingType) referenced by ValueSet packaging-type bound to element PackagedProductDefinition.packaging.type; CodeSystem: package-material (PackageMaterial) referenced by ValueSet package-material bound to element PackagedProductDefinition.packaging.material;
