- **Description**: The AdministrableProductDefinition references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: administrable-dose-form (AdministrableDoseForm) referenced by ValueSet administrable-dose-form bound to element AdministrableProductDefinition.administrableDoseForm; CodeSystem: unit-of-presentation (UnitOfPresentation) referenced by ValueSet unit-of-presentation bound to element AdministrableProductDefinition.unitOfPresentation; CodeSystem: target-species (TargetSpecies) referenced by ValueSet target-species bound to element AdministrableProductDefinition.routeOfAdministration.targetSpecies.code; CodeSystem: animal-tissue-type (AnimalTissueType) referenced by ValueSet animal-tissue-type bound to element AdministrableProductDefinition.routeOfAdministration.targetSpecies.withdrawalPeriod.tissue;
