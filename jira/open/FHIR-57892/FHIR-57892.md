- **Related Artifact(s)**: ValueSet
- **Grouping**: TEXTONLY
- **Description**: Change:

[Preferred] or [Example] - Send whatever you like, from the value set or not, including just text.

To:

[Preferred] - Implementers are encouraged, but not required, to use a code from the specified value set. Permissible to send only text.

[Example] - The specified value set is illustrative only; there is no expectation of use.

Because:

'Send whatever you like' seems sarcastic and unhelpful, and the existing description fails to capture the distinction between preferred and example binding.
