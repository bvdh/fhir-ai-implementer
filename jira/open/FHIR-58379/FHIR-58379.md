- **Description**: The current definition of the handle-unclosed-expansion input parameter is as follows:

If true this asserts that you will correctly handle an unclosed expansion and the returned expansion SHALL include the valueset-unclosed extension if the value set is unclosed. If handle-unclosed-expansion is set to false the server SHALL return an error if the value set is unclosed.

This description creates a hard dependency between the normative FHIR specification and the ValueSet Unclosed extension which is not yet normative - currently it is FMM3.

To address this, the following options are proposed:
1. The element described by the extension be included as a native element in the ValueSet resource type (i.e. ValueSet.expansion.unclosed).

2. The handle-unclosed-expansion be removed from the core specification and added to the Terminology Module Incubator.
