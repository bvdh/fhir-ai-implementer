- **Resolution Description**: Given that List can hold a single reference, we want to avoid overmodeling the resource so we enable implementers flexibility in downstream IGs.
- **Description**: List is the only resource type allowed to be referenced from DiagnositcReport.comparison. That creates complexity when referencing only one resource (e.g., a prior ImagingStudy), and it has an ordered structure built in that might not be necessary or might even be misleading when the order of the elements is not important.

Please consider referencing any resource instead, which also allows List in the use cases where this is necessary.
