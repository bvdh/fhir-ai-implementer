- **Description**: Below the structure display of each resource in the FHIR specification there is this text:
See the Extensions for this resource

The link points to the Profiles for this resource; extensions are no longer available on the referenced page:
https://build.fhir.org/device-profiles.html#extensions

Proposed solution:

fix the link to point to https://build.fhir.org/ig/HL7/fhir-extensions/extension-registry.html
fix the text to state that it points to profiles only
update the generated page with profiles to include a section with the extensions
a combination of the above....
