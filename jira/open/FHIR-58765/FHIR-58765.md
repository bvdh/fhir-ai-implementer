- **Description**: We have telecom based search parameters (phone, email, telecom) on Patient, Practitioner, PractitionerRole, and Person. We don't have it on Organization, Location, or HealthcareService. However, the use-case for searching by telecom is the same for all of these - I've got the phone number/email address and I want to find the whole record. I realize that these are using a more complex data type (ExtendedContactDetail rather than just ContactPoint), but that shouldn't interfere with the ability to searching.
