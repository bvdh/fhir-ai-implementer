- **Change Category**: Correction
- **Description**: In the "Scope and Usage" section it currently reads: "message on her clinician app (Communication) or sees such message flagged in the EMR (Flag)."
But it should have an "a" in there and it should be "sees" like: "sees such a message"

In the "Boundaries and Relationships" section it reads: "Subscription differs from from DeviceAlert" the word "from" appears twice, so it should be: "Subscription differs from DeviceAlert"

In the alt text (hover text) for the devicealert-state-machine.svg image, it reads: "The DeviceAlert state machine showing relationship between the DeviceAlert status and signal annuciation." The last word being a misspelling of "annunciation" so the new alt text should be: "The DeviceAlert state machine showing relationship between the DeviceAlert status and signal annunciation."
