- **Description**: If a medication in a medication plan is a continuous medication and has no concrete end date e.g. should be taken long term then the dosage should be able to reflect this.

The proposed solution to "Add repeatCycle (Duration) to DosageInstruction 0..1" https://jira.hl7.org/browse/FHIR-54252 allows to repeat cyclical dosage schemes that include several steps, however, it forces the author to give a concrete time period. By using the duration datatype it is not possible to state repeat this "until further notice".

Proposed solution: change the dataType of "repeatCycle" to allow for general repetition (without a defined end) in addition to a concrete time period e.g. repeatCycle[x] as a choice between boolean and Duration.
