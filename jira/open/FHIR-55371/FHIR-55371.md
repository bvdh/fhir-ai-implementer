- **Resolution Description**: Decision is a modifier, but it's optional and there's no "meaning if missing", so it's not clear how things behave if it's missing.

This has now been clarified by adding a constraint that requires decision to be present if there are any provisions. We will provide additional text to reflect the thinking behind this: if consent is not intended to be computable the decision element and provisions are optional and the consent only captures the metadata. If it is intended to be computable, decision element is required and the provisions can be optionally used to record further constraints and exceptions to the decision.

Also, it's not clear how to provide provisions that grant and other provisions that prohibit. Shouldn't this appear on provision (with a meaning if missing of 'inherit from parent' and it being an error if there's nothing to inherit?

This has been discussed in the section 6.2.8 Provisions in detail and it has also been clarified how to process conflicts in the last paragraph of this section.
