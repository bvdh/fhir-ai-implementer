- **Resolution Description**: Update the Documentation of the issues output parameter for CodeSystem $validate-code from:

> List of itemised issues with paths constrained to simple FHIRPath. Examples are CodeableConcept, CodeableConcept.coding[0], CodeableConcept.coding[1].display, or Coding.display

to:

> List of itemized issues with paths constrained to simple FHIRPath (see OperationOutcome.issue.expression), with the exception that expression paths can refer to parameter names in the input parameters resource. For example: `code`, `codeableConcept`, `codeableConcept.coding[0]`, `codeableConcept.coding[1].display` or `coding.display`

Apply this same update to the ValueSet/$validate-code issues output parameter documentation.
