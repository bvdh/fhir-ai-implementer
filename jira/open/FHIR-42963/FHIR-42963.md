- **Description**: EOBs aren't only used when submitting a claim, prior auth or predetermination. EOB is also used to just provide a point-in time assertion of "Where are things at?" with respect to a coverage and will reflect information about claims, prior auths and potentially pre-determinations to date, as well as reflecting remaining deductibles, etc. There is a need to communicate instances that were generated at a particular point-in-time rather than in response to a 'process' request for a particular Claim instance.

### 2. Lloyd McKenzie - 2024-02-01

In Ontario, system users can ask for an EOB at any point to retrieve the current status of coverage - what claims have been submitted, what's been paid, how much remains of deductible to be collected, etc. This is going to be done over a FHIR interface and EOB is the only logical resource to so it. (Also, as a patient, I receive quarterly and annual EOBs that summarize everything that's happened in my business. If it was done electronically rather than by paper, I'd expect it to be an EOB.)
