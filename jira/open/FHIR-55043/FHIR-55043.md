- **Description**: The ClinicalUseDefinition references several value sets that are potential candidates for migration to THO. While value set migration is not required, if it's realistic for the value set definition to need to change in the coming years, or the value sets might be useful in CDA, V2 or other specs, migration should be considered. Specifics: CodeSystem: clinical-use-definition-category (ClinicalUseDefinitionCategory) referenced by ValueSet clinical-use-definition-category bound to element ClinicalUseDefinition.category; CodeSystem: undesirable-effect-frequency (UndesirablEffectFrequency) referenced by ValueSet undesirable-effect-frequency bound to element ClinicalUseDefinition.undesirableEffect.frequencyOfOccurrence; CodeSystem: product-intended-use (ProductIntendedUse) referenced by ValueSet product-intended-use bound to element ClinicalUseDefinition.indication.intendedEffect; CodeSystem: therapy-relationship-type (TherapyRelationshipType) referenced by ValueSet therapy-relationship-type bound to element ClinicalUseDefinition.indication.otherTherapy.relationshipType; CodeSystem: interaction-type (InteractionType) referenced by ValueSet interaction-type bound to element ClinicalUseDefinition.interaction.type; CodeSystem: interaction-incidence (InteractionIncidence) referenced by ValueSet interaction-incidence bound to element ClinicalUseDefinition.interaction.incidence; CodeSystem: warning-type (WarningType) referenced by ValueSet warning-type bound to element ClinicalUseDefinition.warning.code;
