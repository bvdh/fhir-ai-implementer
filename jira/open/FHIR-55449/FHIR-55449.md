# FHIR-55449: Value sets that are "all codes in code system x" need a more efficient expansion representation

- **Description**: Value Sets with a definition of "all codes in code system X" are essentially communicating to implementers that any valid code from code system X is conformant. Forcing systems to create, and more importantly, exchange all of the codes from code system X in a value set expansion is overly burdensome the vast majority of times. We need a way for a value set terminology service to communicate that it is providing a conformant expansion without sending all the codes from the code system. Perhaps this could simply be something like a pointer to a known conformant FHIR terminology server that can provide membership validation. Or maybe even code system search. But we need to allow that a conformant expansion all all codes is not always needed.
