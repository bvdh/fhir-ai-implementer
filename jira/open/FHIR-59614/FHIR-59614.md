- **Description**: In the Composition.relatesTo comment block it's showing an outdated relatesTo structure as an example, it currently shows:
"relatesTo": [{
"type": "replaces",
"targetReference": {
"identifier":
{
"system": "...",
"value": "..."
}
}
}]

But Composition.relatesTo.type is now a CodeableConcept, so it should look like this:
"relatesTo": [{
"type": {"coding":[
{"system": "http://terminology.hl7.org/CodeSystem/artifact-relationship-type", "code": "replaces", "display": "Replaces" }
] },
"targetReference": {
"identifier":
{
"system": "...",
"value": "..."
}
}
}]

You could also include line-breaks and indentations too.
