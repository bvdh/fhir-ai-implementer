- **Description**: Description:
Ballot 5 advances Specimen to Normative, but the currently published release (R5, 5.0.0) has this resource at Maturity Level 2 / Trial Use. Going from FMM 2 straight to Normative is a large jump — FMM 2 is near the bottom of the maturity scale and doesn't reflect the "widespread use in production across the full range of intended environments" we'd expect before locking a resource down.

What makes this more concerning is that the same ballot also makes several non-backward-compatible changes to the resource: accessionIdentifier is removed, container.location is removed, processing.additive is restructured from a Reference(Substance) into a BackboneElement, collection.bodySite is renamed to bodyStructure, and container.device changes type from Reference to CodeableReference. On top of that, a new SHALL-level constraint (spm-1) is introduced. A resource that is still reshaping its data model this heavily hasn't stabilized, and Normative status will make comparable corrections very difficult going forward.

Proposed resolution:
Keep Specimen at Trial Use for at least one more cycle so the recent changes can be exercised in production. If the work group wants to advance the stable core, at minimum hold the elements changed in this ballot — focus, processing.additive, and the new processing.performer/processing.device — at Trial Use within an otherwise-Normative resource.
