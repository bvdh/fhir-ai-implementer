## Comments

### 1. Jose Costa-Teixeira - 2026-10-06

Requesting to revisit this disposition. The resolution ("We will move non-example-binding value sets to THO") uses the binding strength as the criterion. THO guidance is that the criterion is whether the content is appropriate for production use: an example binding that's appropriate for production use could conceivably have a tighter binding downstream, and thus should be maintained in THO. Content that is only illustrative should be marked experimental = true (value set and code system) and stay in core.

Proposed revised resolution (Persuasive with Modification): value sets and code systems appropriate for production use move to THO, whatever their binding strength; illustrative content is marked experimental and stays in core.

Impacted value sets:

medication-ingredientstrength (codes qs, trace) – bound to Medication.ingredient.strength[x], preferred binding; experimental (value set / code system): true / false. Move to THO. Production use (preferred binding). The value set flag experimental = true contradicts the preferred binding and should be false.
