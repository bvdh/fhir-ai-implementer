# FHIR-59601: Cross version extensions with required _datatype extension declare the extensions as 0..*

- **Description**: The xver 0.1.0 Extension-ServiceRequest.reason StructureDefinition declares its nested Extension.extension element with a minimum cardinality of 0, while requiring the _datatype slice at 1..1. The optional concept and reference slices do not change that minimum.

When the IG Publisher generates a snapshot for a profile using this extension, it reports that the nested slices require at least one child but the sliced element allows zero. This is reproducible in the R4 ServiceRequestOrderEuImaging profile.

This issue is present in all crossversion extensions with a required _datatype slice.

Please set the minimal number of extensions in the definition to 1 in these extensions.
