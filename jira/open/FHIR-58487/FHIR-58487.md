SPDX License
The license that applies to an Implementation Guide (using an SPDX license Identifiers, or 'not-open-source'). The binding is required but new SPDX license Identifiers are allowed to be used (https://spdx.org/licenses/).

Regulatory expression: Strength: required Corresponding description: "The license that applies to an Implementation Guide (using an SPDX license Identifiers, or 'not-open-source'). The binding is required but new SPDX license Identifiers are allowed."

A required binding indicates that the coded value must come from the bound value set. The description simultaneously states that new SPDX license identifiers are allowed, which permits values outside the required binding and therefore contradicts the regulatory expression.

Either change the strength to extensible if new SPDX license identifiers are intentionally permitted, or revise the description to: "The license that applies to an Implementation Guide. The value must be an SPDX license identifier or not-open-source."
