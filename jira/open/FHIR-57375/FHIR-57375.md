- **Resolution Description**: New concepts are being added to a new THO code system via UP-873 and will be included in the FHIR value set. We have decided to add abbreviation, short name, and consumer. Additional comments can be made on this ticket.

Inactive/retired is a status and not a designation use so it does not belong in the code system.

New codes can be proposed through the UTG process if this does not satisfy the needs listed in this ticket.

- **Description**: Considering recurring related discussions in Zulip, I propose to add concepts to the DesignationUse value set. Currently the value set only includes two concepts from SNOMED CT, but there are other frequently used values that could be defined in a HL7 code system. Potential new concepts I see asked in Zulip include:

display
abbreviation
short name
formal
plural form
patient friendly name
inactive/retired
