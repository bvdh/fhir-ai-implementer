- **Description**: Section 14.7.0.2 seems to reference the use of the Timing data type but none of the elements in DosageDetails use Timing (only RelativeTime). In fact, there doesn't seem to be a way to designate a timing other than relative to an event (unless it's through the Dosage data type used for .simple or .step.component). Should step.start and step.end be data type choices between Timing and RelativeTime?
