# FHIR-52901: How should cyclical dosage schedules be represented?

## Metadata

- **Specification**: FHIR Core (FHIR)

- **Work Group**: Pharmacy
- **Related Artifact(s)**: MedicationRequest
- **Resolution Description**: Cyclical regimens are represented with repeatCycle (FHIR-54252, applied by FHIR-58720). For example, an oral contraceptive taken once daily for 21 days followed by 7 days without tablets is one step with a component taken once daily, bounded to 21 days, and repeatCycle = 28 days. This is the example added for FHIR-54252.
- **Description**: Some therapies follow a cyclic regimen (e.g., oral contraceptives: 21 tablets daily, then 7 days break. These regimens are clinically common and safety-critical. What is the recommended way within R6 to model these cyclic patterns so that systems can safely interpret and exchange them?
