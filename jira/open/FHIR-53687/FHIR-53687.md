- **Resolution Description**: In the DosageDetails section of the Dosage page, after "When there is more than one component dosage in a step, all components within the same step are considered concurrent." (as corrected by FHIR-58594), add:
Concurrent means that the components apply during the same step, not one after the other. Each component has its own timing, so the components in a step can apply on different days or at different times of the day, or only as needed.
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: The description for the use of multiple components indicates that when there are multiple components in a step, they are all considered concurrent, but in the examples of reasons to use multiple components, it indicates that different dosages may be given on different days or at different times. This example (and maybe the PRN example too) don't feel like they would be concurrent. Please clarify this meaning.
