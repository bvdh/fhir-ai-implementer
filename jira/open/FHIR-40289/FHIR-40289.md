- **Description**: The recently renamed (in response to FHIR-39242) conformsTo elements in both Device and DeviceDefinition allow documenting conformance claims. However there is an outstanding issue from that tracker for documenting sub-standard conformance, including IHE Actor and Named Option conformance; DICOM SOP class conformance; other option capabilities in standards; and applicable clauses in regulation.

Options for addressing these could be: the standard vocabulary used includes both the standard and options; new elements for options (and sub-options); and extensions for options and sub-options.

Clarify how these should be handled, and if necessary update the resource structures and narratives, or create extensions.
