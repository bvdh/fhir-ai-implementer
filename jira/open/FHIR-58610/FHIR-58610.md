- **Description**: It is recommended that the support for Additional Resources in OperationDefinition be clarified in the resource type's description. Currently, it seems as though:

The types in which an operation can be executed (OperationDefinition.resource element) does not appear to support additional resources given the binding.
The types support for an operation parameter (OperationDefinition.parameter.type element) does not appear to support additional resources given the binding.

Whether or not the above are intentional, it would be helpful to clarify if (and how) additional resources are supported by OperationDefinition instances.
