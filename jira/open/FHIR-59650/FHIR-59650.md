- **Description**: The spec says "If there is only one out parameter, which is a single Resource with the parameter name "return" then the parameter format is not used, and the response is simply the resource itself". However, it doesn't make clear whether the "if there is only one" applies to the operation definition or to the operation invocation result.

I strongly feel it applies to the operation definition. However, regardless, it needs to be clarified.
