- **Description**: The datatype for DeviceAssociation.device should be changed from Reference to CodeableReference to allow for statements such as "The Patient uses a pacemaker", "The patient uses a wheelchair" by simply putting a code for the type of device in DeviceAssociation.device.concept.

In many cases, where no details about the device are known, just the fact that the patient uses one of a specific type, the creation of a Device instance only to populate device.type, would be overkill.

Especially with the 1..1 cardinality, DeviceAssociation.device should allow for more flexibility to address different needs.
