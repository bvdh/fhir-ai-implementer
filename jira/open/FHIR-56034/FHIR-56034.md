- **Description**: Proposal

Add "or missing" modifiers to the search standard:

:or-missing - all search types to support finding fixed. pattern, min/maxValue constraint optional elements
:exact-or-missing - for string to find fixedString on optional elements
:in-or-missing - token for required binding on optional elements

Justification

Most profile "hard" constraints have equivalent searches that can satisfy or at least significantly narrow the candidates for resources conformant to the profile.

For example, a profile with
fixedCode: "male"

for Patient.gender can be completely converted to a search:
Patient?gender=male

if the element is required.

If the element is optional however, the best case is a pair of searches, one with the fixed value and one with
?gender:missing=true

When multiple constraints are combined, this leads to an explosion of combinations.
