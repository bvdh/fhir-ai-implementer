- **Description**: The description of the fatal-error (and potentially a new non-fatal-error) in the Response Type value set (https://hl7.org/fhir/valueset-response-code.html) indicates a SHALL requirement to include details in the narrative describing the issue. Presumably "narrative" refers to the content of the OperationOutcome references in response.details. If this is the case, an invariant should be added to .details that ups the cardinality to 1..1 if the value of .code is fatal-error (and any other code that has a similar SHALL requirement)
