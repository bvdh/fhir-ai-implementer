- **Description**: We currently define an implicit code system for StructureDefinition resources so that we can map to elements defined in them. When doing such mapping, sometimes there is a desire to map to an extension instead of an element.

I request adding an implicit code system definition for the ImplementationGuide resource that would contain the canonical URLs for that guide.

CodeSystem property
Value

URL (CodeSystem.url)
ImplementationGuide.url

Concept (CodeSystem.concept)
Each canonical resource defined by the IG corresponds to a code system concept

Display (CodeSystem.concept.display)
The title of each canonical resource (CanonicalResource.title) if one exists, otherwise the name (CanonicaResource.name)

Code (CodeSystem.concept.code)
The canonical URL of the resource (CanonicalResource.url)

Definition (CodeSystem.concept.definition)
CanonicalResource.description if one exists, otherwise CanonicalResource.purpose (might be reversed order?)

Thanks!
