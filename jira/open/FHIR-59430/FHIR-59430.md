- **Description**: The "use CodeableReference" for bodySite guidance should allow for a single search parameter that covers both CodeableRefernce.concept and CodeableReference.refernce.resolve()... thereby preventing users to explicitly search for both variants.

This was discussed at the May 2026 WGM in Rotterdam where is was stated that such functionality should be possible. This ticket is the formal request for such functionality to be added to the core spec.
