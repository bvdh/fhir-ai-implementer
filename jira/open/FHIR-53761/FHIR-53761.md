- **Resolution Description**: Will update

A resource type parameter is a special case parameter type that is used to enable chaining through elements that are actual resources (e.g., Bundle.entry.resource).

to:

A resource type parameter is a special case parameter type that is used to enable chaining through elements that are actual resources (e.g., Bundle.entry.resource) embedded within another resource (e.g., resources in a Bundle).

Note that this search type cannot be used to chain into contained resources. For details on searching contained resources, see _contained.
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: The documentation on this new search parameter type is rather minimal for those new to this parameter type.

"A resource type parameter is a special case parameter type that is used to enable chaining through elements that are actual resources (e.g., Bundle.entry.resource). ", suggestion:

"A resource type parameter is a special case parameter type [ see section 3.2.1.5.16]that is used to enable chaining through elements that are actual resources (e.g., Bundle.entry.resource) embedded within an overarching resource (e.g. Bundle)"
