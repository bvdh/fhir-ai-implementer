- **Description**: The currently existing mea-1 rule:

mea-1
Rule
(base)
Stratifier SHALL be either a single criteria or a set of criteria components
group.stratifier.all((code | description | criteria).exists() xor component.exists())

I think it's worth looking at the Measure invariant mea-1, because it looks like it needs updating to me. Measure.group.stratifier.groupDefinition was added in FHIR R5, so I think it's a good idea to add to the constraint mea-1 as a possible acceptable field.

Also it's a little surprising to me that if a group.stratifier.description exists then a component cannot exist. Is that the intention? I was thinking it could be an overall description of all the components (which each can have their own individual description).
