- **Description**: The grp-2 constraint rule's description says: "Group.type SHALL be defined if Group.membership is either 'definitional' or 'enumerated'"

And the expression is: type.exists() or (membership = 'conceptual')

But the problem is if Group.type doesn't exist and Group.membership also doesn't exist, then that statement is false and it will cause the Resource to fail validation (I believe). So we need to fix the expression.

Suggested fix that will work for most validators: type.exists() or (membership = 'conceptual') or membership.empty()
