- **Description**: We should review the ResearchStudy search parameters.

In ResearchStudy the "status" search parameter description's code list is listing the R4 codes and not the ones changed since then. It should be: draft | active | retired | unknown

The "description" search parameter only searches the "description" element but there's also a "descriptionSummary" element, consider expanding what elements it searches.

There's an "eligibility" search parameter only for ResearchStudy.recruitment.eligibility so maybe consider either expanding or adding a search parameter for ResearchStudy.comparisonGroup.eligibility.

The "date" search parameter is being used for ResearchStudy.period and not ResearchStudy.date, this might lead to confusion, so maybe change the name of the "date" search parameter or make some other change for it.

Also consider declaring ResearchStudy as a CanonicalResource interface to get the "url" and "version" search.

Elements that could have search parameters added for ResearchStudy:

url and version
ResearchStudy.label.value
ResearchStudy.purposeType
ResearchStudy.comparisonGroup
ResearchStudy.recruitment.actualGroup
ResearchStudy.objective.outcomeMeasure (endpoint, population, intervention, comparator, and maybesummaryMeasure or endpointAnalysisPlan)
ResearchStudy.result
ResearchStudy.progressStatus.state
ResearchStudy.relatesTo.type and ResearchStudy.relatesTo.target[x]
