- **Description**: There are 3 input parameters related to designations / descriptions in $expand.

includeDesignations (Boolean)
designation (token) A token that specifies a system+code that is either a use or a language. Designations that match by language or use are included in the expansion. If no designation is specified, it is at the server discretion which designations to return
displayLanguage (code) Specifies the language to be used for description in the expansions i.e. the language to be used for ValueSet.expansion.contains.display

Is it safe to assume that #2 and #3 are evaluated only if includeDesignations is true?

If yes, please add documentation explaining how the values for designation and displayLanguage interact if at all (e.g. are they complementary or would a value for one that is different than the other override the other, or would the values be additive), including guidance that explains how to use the input parameters to return for example all the French concept designations for each concept.
