- **Description**: the out parameter on the $translate operation has two definitional problems:

it doesn't say which concept map is the origin in the case of a set of concept maps that refer in a line in ConceptMap.group.unmapped.otherMap. The purpose of the originMap is to allow users to know where a translation came from so they know where to go chasing errors. for this reason, the originMap should be defined as the outer concept map in the case where they are linked using otherMap

if there's multiple Maps and they all have the same translation, then the mapping should only be found once, with the multiple stated originMaps. So the cardinality of originMap should be 0..*
