- **Related Page(s)**: Metadata Types
- **Related Section(s)**: 2.1.30.5.0.2
- **Resolution Description**: Agreed, the types are supposed to be the same as what is defined in the extension:

https://hl7.org/fhir/extensions/StructureDefinition-cqf-valueFilter.html

We will update the value[x] types to:

boolean, integer, string, Quantity, Range, Ratio, and RatioRange

In addition, we will define a constraint to ensure that either, a path or searchParam must be provided, but not both.
- **Resolution Vote**: Grahame Grieve/Michael Donnelly: 12-0-0
- **Vote Date**: 2026-01-27
- **Change Category**: Correction
- **Change Impact**: Non-substantive
- **Description**: DataRequirement.valueFilter.value[x] has dateTime, Period, and Duration as allowed types.

These are the same types as DataRequirement.dateFilter.value[x].

The allowed types are seemingly more restrictive than the data element description:
Value filters specify additional constraints on the data for elements other than code-valued or date-valued
