- **Resolution Description**: Agree to allow passing the StructureMap, though not sure it'll be useful for complex maps due to dependencies. We don't allow Reference any other places we allow canonical, don't see a good reason to break with that pattern here. If there's a strong-use-case for Reference in addition to canonical, please submit a new tracker with a well-explained rationale.
- **Resolution Vote**: Rick Geimer/Ewout Kramer: 10-0-1
- **Vote Date**: 2020-03-02
- **Change Category**: Enhancement
- **Change Impact**: Compatible, substantive
- **Applied for Version**: R5
- **Description**: The current StructureMap.$transform operation does allow passing of the URI of a referred to StructureMap. In analogy to Questionnaire.$populate $apply, it should also support passing the StructureMap resouce directly.

We should extend the input parameters with:

IN structureMap 0..1 StructureMap The StructureMap to use in the transform.

IN structureMapRef 0..1 Reference The StructureMap reference to use in the transform.
