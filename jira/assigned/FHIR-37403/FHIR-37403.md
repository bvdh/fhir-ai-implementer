- **Description**: The valueset that determines the values of the Composition.status (https://build.fhir.org/valueset-composition-status.html) is misaligned with the values allowed for DiagnosticReport.status field (https://build.fhir.org/valueset-diagnostic-report-status.htm).
Both resources have a similar lifecycle. But the ValueSets are not the same.

The DiagnosticReport valueset allows to differentiate between de initial creation, creation and preliminary versions of a document. This is something that is also required for Composition.

I suggest that Composition support the same values as DiagnosticReport, possibly by referring to the same ValueSet.
