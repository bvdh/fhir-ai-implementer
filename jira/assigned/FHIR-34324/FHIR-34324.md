- **Resolution Description**: Will clarify to say that "This operation returns a 200 Ok provided that it was possible to perform validation, irrespective of whether validation issues were found. However, it is possible that certain errors in the validated content (e.g. invalid character set, broken JSON, etc.) may cause the overall validation operation to fail with a 4xx or 5xx series response."
- **Resolution Vote**: Gino Canessa/Marco Visser: 13-0-0
- **Vote Date**: 2022-03-21
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Applied for Version**: R5
- **Description**: The $validate operation has the following text:

"This operation returns a 200 OK whether or not the resource is valid. A 4xx or 5xx error means that the validation itself could not be performed, and it is unknown whether the resource is valid or not."

Is this correct? For instance, HAPI returns 412 Precondition Failed when the resource is not valid.
