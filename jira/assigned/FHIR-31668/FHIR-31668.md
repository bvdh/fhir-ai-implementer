This was true in STU3, but is no longer true.

STU3 has Composition.class 0..1 which maps nicely to XDS classCode

R4 has Compositioncategory 0..* which has different name, cardinality and usefulness to XDS classCode. A simple link to the XDS spec is unhelpful. Remove the comment or make it useful.
