- **Resolution Description**: TI will reach out to public health to remove the extension in the medmorph IG. The other extensions in other IGs have already been removed.

TI will update the extension description and definition.

Change "An extra warning about the correct use of the value set."

To: "A warning about how to interpret and/or correctly use the value set. This is intended for anyone engaging with the value set definition or its expansion. For example, a warning advising of licensing requirements for code systems the value set relies upon."

- **Vote Date**: 2024-05-23
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: These extensions all appear to be duplicates and to be poorly defined:

http://hl7.org/fhir/uv/cpg/StructureDefinition/cpg-usageWarning

http://hl7.org/fhir/us/medmorph/StructureDefinition/us-ph-usagewarning-extension

http://hl7.org/fhir/uv/crmi/StructureDefinition-crmi-usageWarning.html

http://hl7.org/fhir/us/cqfmeasures/StructureDefinition/cqfm-usageWarning

http://hl7.org/fhir/StructureDefinition/valueset-warning

I suggest that the TI Wg defines the warning extension a little more (who should be shown these warnings? How are they different to purpose? When would it be safe to use this extension), and asks the other committees to retire their other extensions.
