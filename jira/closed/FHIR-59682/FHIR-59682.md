- **Description**: The Pharmacy WG resolved FHIR-54340 (Persuasive with Modification, 12-1-0): "Change DosageDetails datatype name to DosageInstruction". The data type DosageDetails, introduced in R6 for complex dosage regimes (steps, components, safety), is now named DosageInstruction. Its content is unchanged: renderedInstruction, repeatCycle, step (start, end, count, component, safety) and safety.

ActivityDefinition.dosageInstruction uses this data type. Since there is no DosageDetails type any more, the type of the element had to change with the rename, so that the build stays consistent. This was done in the same PR as the Pharmacy resources (PR 4347, merged 2026-10-20):

ActivityDefinition.dosageInstruction: type DosageDetails → DosageInstruction. Cardinality, definition and content are unchanged.
A release note was added in the ActivityDefinition introduction, under "Changes since 6.0.0-ballot5", referring to FHIR-54340.

The change can be seen on build.fhir.org.

As ActivityDefinition is a CDS resource, this ticket asks CDS to confirm the change in their resource (and, if CDS prefers, to adjust the release note or record it under this ticket).
