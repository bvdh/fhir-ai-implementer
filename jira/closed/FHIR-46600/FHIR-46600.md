# FHIR-46600: AdverseEvent.category code (hospital-aquired-infection) is misspelled

## Metadata

- **Summary**: AdverseEvent.category code (hospital-aquired-infection) is misspelled
- **Created**: 2024-08-08
- **Updated**: 2026-08-06
- **Resolved**: 2026-06-04
- **Status**: Applied
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Michelle Miller
- **Resolution**: Persuasive with Modification
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Patient Care
- **Related URL**: http://build.fhir.org/valueset-adverse-event-category.html
- **Related Artifact(s)**: AdverseEvent
- **Resolution Description**: Retire misspelled code

Add new (correctly spelled) code with the following display/definition.

Hospital Acquired Infection
The adverse event pertains to a hospital acquired infection.
- **Resolution Vote**: Jay Lyle / Rob Hausam : 5-0-0
- **Vote Date**: 2026-06-04
- **Change Category**: Correction
- **Change Impact**: Compatible, substantive
- **Applied for Version**: R6
- **Description**: eventCategory uses values from the code system AdverseEventCategory, which has a misspelling in "hospital-aquired-infection" it should be acquired.
