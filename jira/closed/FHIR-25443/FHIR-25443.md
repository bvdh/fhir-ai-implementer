- **Resolution Description**: There is already a class that can be declared on table that cause grid lines to appear. Because "no lines" has been the default for so long, it's problematic to change that default now. However, we will update the sample-ig with examples of tables both with and without grid lines so it's more obvious to authors how to get whichever rendering approach they prefer.

- **Description**: Tables in the new IG templates lack gridlines. Combined with the default centered vertical alignment, this makes tables quite hard to read in some cases. Please add gridlines, like the rest of the specification.
