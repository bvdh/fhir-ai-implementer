### 3. Rene Spronk - 2024-07-05

If we assume the versioning of canonical artifacts to use semantic versioning, does that mean that if we're search an artifact by using the 'url' and 'version' parameters (or a | version in the url) that the version should be a 'semantic version match' ?

The question boils down to: does the 'version' parameter use ':below' as a default matching mechanism [if the version is interpreted as using semantic versioning], or is it an exact match (':exact') ?

If you want to include patches, I would exclude that portion from the reference (e.g., |1.0 instead of |1.0.0). IMO (and based on the current rules), all specified components need to match. So fully qualifying a version should only ever match that version exactly.

Please clarify usage of semantic versioning when searching.
