- **Resolution Description**: Will add a section under "Additional Resources defined Outside This Specification", titled: "Moving to FHIR Core". The section will describe the process of moving a resource from an 'additional' space into FHIR Core.

Generally, the process is:

The responsible WG/WGs need to request moving into core.
FMG needs to approve moving into core (criteria TBD by FMG).
The resource will be added to the next ballot of FHIR core.
The resource will be officially available when the milestone release that includes it is published.
Concurrently with that FHIR Core publication, the status of the 'additional' definition should be updated.
