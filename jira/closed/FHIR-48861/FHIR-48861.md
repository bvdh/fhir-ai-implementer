# FHIR-48861: Add status "ended" to Request pattern

- **Status**: Applied

- **Raised in Version**: R6
- **Work Group**: FHIR Infrastructure
- **Related Artifact(s)**: Request Pattern
- **Grouping**: Workflow
- **Resolution Description**: We will define a new status of 'ended' with the definition:

"This request is no longer to be acted upon. This status does not differentiate what degree of action (if any) has already been undertaken against the request."

We will make this a parent of completed, stopped and cancelled.
- **Resolution Vote**: Jose Costa Teixeira/John Hatem: 5-0-1
- **Vote Date**: 2024-11-18
- **Change Category**: Enhancement
- **Change Impact**: Compatible, substantive
- **Applied for Version**: R6
- **Description**: Similar to MedicationRequest, the other Requests should have a value for a higher-level "ended" status - where the status is an end state, regardless if it is completed, stopped or cancelled.
