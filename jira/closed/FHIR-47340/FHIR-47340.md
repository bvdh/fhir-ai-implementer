- **Resolution Description**: Change the Subscription.managingEntity definition from:

Entity with authorization to make subsequent revisions to the Subscription and also determines what data the subscription is authorized to disclose.

to:

Entity with authorization to communicate with the server about this Subscription, such as requesting changes (e.g., updating an endpoint URL).

Add a note:

Note that the manging entity for a subscription does not need to be the client (e.g., in the case of server-managed Subscriptions).

- **Description**: managinEntity is defined as:
Entity with authorization to make subsequent revisions to the Subscription and also determines what data the subscription is authorized to disclose.

Is this entity that creates the Subscription and receives the events or the entity than sends the events and updates the status when an error occurs? I assume the first. I suggest to change the sentence to reflect that.
