- **Description**: The description of item.answerValueSet could benefit from a mention of the [preferred terminology server extension](https://www.hl7.org/fhir/extensions/StructureDefinition-preferredTerminologyServer.html) since in order to show that list, in most cases you need to be able to expand the ValueSet URL. Some suggested text to add:

"If the ValueSet requires a terminology server to provide an expansion, a preferred terminology server can be provided with an [extension](https://www.hl7.org/fhir/extensions/StructureDefinition-preferredTerminologyServer.html) on the Questionnaire item."
