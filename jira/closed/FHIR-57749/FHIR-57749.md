- **Description**: There are a couple more fields used as key defining properties, that SubstanceDefinition lacks.

1. It is important to be able to distinguish substances by their Glycosylation Type
Propose to add SubstanceDefinition.glycoslyationType 0..1 CodeableConcept
and add an example value set (e.g. human, mammalian, old-world-monkey, mouse, mammalian-afucosylated, avian, insect, yeast, yeast-humanised, plant, bacterial)

2. For a protein it is important to know the general modification type.
Propose to add SubstanceDefinition.protein.modificationType 0..1 CodeableConcept
and add an example value set (e.g. PEGylated, lipidated, Fc-fused, albumin-fused, drug-conjugated, polysaccharide-conjugated, glycoengineered, amino-acid-substituted, truncated, biotinylated, fluorescent-labeled)

Since these are known to be "defining" concepts for substances, it is better for these to be in core rather than extensions. There are many other extra fields that could be added to SubstanceDefinition, but the majority can be extensions. This change satisfies all the defining concepts.
