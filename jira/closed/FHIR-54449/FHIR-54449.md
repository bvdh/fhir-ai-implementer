- **Resolution Description**: We will change the short description and definition of adherence.reason to
"The reason for the current adherence status."
We will remove the comment.

We will change the short description and definition of adherence to
"Indicates whether the medication is or is not being consumed or administered as directed"
- **Resolution Vote**: Tom de Jong / Joao Almeida : 7 - 0 - 0
- **Vote Date**: 2026-05-19
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: adherence Structure - Confusing Semantics

adherence.code: "Type of adherence for the medication"
Binding: MedicationStatementAdherenceCodes (Example)

adherence.reason: "Captures the reason for the current use or adherence of a medication"

short: "Details of the reason for the current use of the medication"

comment: "This is generally only used for "exception" statuses such as "entered-in-error". The reason for performing the event at all is captured in reasonCode, not here."

Issues:

adherence.reason talks about "reason for current use" - but adherence is about WHETHER a medication is being taken according to instructions, not WHY
The reason element (at the resource level) already captures "why the medication is being/was taken"
The comment seems to be a copy/paste error from the MedicationRequest.reasonCode element

Propose:

Change adherence.reason definition to: "reason a medication has not been consumed according to instructions."

Change adherence.reason short to: "Reason for lack of adherance"

Update comment to: "Only used if the patient is not taking the medication as instructed."
