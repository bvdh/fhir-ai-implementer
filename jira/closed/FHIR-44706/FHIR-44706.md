- **Resolution Description**: Add content to Operations:Operation Response:

Update:

An HTTP status code of 4xx or 5xx indicates an error, and an OperationOutcome SHOULD be returned with details.

To:

An HTTP status code of 4xx or 5xx indicates an error, and an OperationOutcome SHOULD be returned with details. Note that an OperationOutcome indicating a failure returned by one of these HTTP codes is not wrapped in a Parameters resource.

Update:

If there is only one out parameter, which is a single Resource with the parameter name "return" then the parameter format is not used, and the response is simply the resource itself.

to:

If there is only one out parameter, which is a single Resource with the parameter name "return" then the parameter format is not used, and the response is simply the resource itself. Note that this is true when the expected response is an OperationOutcome.
