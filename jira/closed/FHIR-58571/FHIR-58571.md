- **Description**: Composition would benefit from a consistent way to represent topics or keywords for document discovery and filtering.

`Composition.category` categorizes the document type, while `Composition.useContext` represents its intended context of use. The new `Composition.classification` element might support topical classification, but this purpose is not explicit and no corresponding standard search parameter is defined.

Please clarify how topics and keywords should be represented in Composition. If `Composition.classification` is intended for this use case, consider adding appropriate guidance, examples and a search parameter. Naming and semantics could be aligned with comparable elements such as `ResearchStudy.keyword` and `Library.topic`.
