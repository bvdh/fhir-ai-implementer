- **Description**: We have a 'textual' recommendation to use the set of standard property URIs defined in the notes section of this page (now moving to a THO code system). However, there is no computable representation of this recommendation. Ideally, we'd make this an 'extensible' binding, but given the resource went normative without the requirement, doing so would be a breaking change. Therefore, I recommend the following:

Define a 'preferred' binding on CodeSystem.property.uri to the code system of the properties defined later in the specification.
