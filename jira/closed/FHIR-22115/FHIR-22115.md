- **Status**: Applied
- **Project**: FHIR Specification Feedback

- **Resolution**: Persuasive
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: STU3
- **Work Group**: FHIR Infrastructure
- **Related Artifact(s)**: EpisodeOfCare
- **Grouping**: Deferred
- **Resolution Description**: We will:

Define a standard search parameter tied to the 'episodeOfCare' extension that can be used on any of the resources that are allowed as context for the extension. It will NOT appear as one of the available SearchParameters on the relevant resources
Update the extension to include a reference to the SearchParameter - ideally automatically
Define a new compartment for EpisodeOfCare
Define a new $everything operation with a scope of the new compartment
- **Resolution Vote**: Grahame Grieve/Rick Geimer: 17-0-0
- **Vote Date**: 2021-11-01
- **Change Category**: Enhancement
- **Change Impact**: Compatible, substantive
- **Description**: The EpisodeOfCare should also have its own compartment, and also $everything operation, in the same way that the Encounter does.
