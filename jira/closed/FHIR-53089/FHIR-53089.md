The code system is not used anywhere. Instead, the relevant value set uses SNOMED codes (https://build.fhir.org/valueset-reason-medication-not-given-codes.html)

Suggest reopening the ticket, moving it to Pharmacy, and encouraging them to go with a resolution of removing the code system.
