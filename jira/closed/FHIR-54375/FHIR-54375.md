- **Status**: Applied
- **Project**: FHIR Specification Feedback
- **Type**: Change Request

- **Related Artifact(s)**: Medication
- **Resolution Description**: We will update the definition of ingredient.role:

replace
Indication of whether this ingredient affects the therapeutic action of the drug.
with
The (typically coded) functional role of the ingredient - for example active, excipient, adjuvant, solvent etc.

we will keep the comment about it complementing the .active element.
- **Resolution Vote**: Frank McKinney / Margaret Weiker : 10 - 0 - 0
- **Vote Date**: 2026-04-27
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: isActive and role have duplicate definitions. Although it states that "This can be used in combination with the isActive element to provide further information about the type of ingredient." The definitions should not be identical.

Propose updating the definition to "A code that defines the functional role of the ingredient," and the short definition to "Ingredient's function".
