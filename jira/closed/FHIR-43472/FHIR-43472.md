- **Resolution Description**: This is a long standing "typo" since Day 1 of FHIR spec. We will no change this since it is Normative and any changes affects all implementation.

- **Description**: There is a typo in the word "codable", which should only have one "e", at the end, see https://www.merriam-webster.com/dictionary/codable.

Let's not repeat the C#'s mistake of ICloneable that can't be fixed anymore.

See the same typo in Observation.valueCodeableConcept (https://hl7.org/fhir/observation.html#observation) and maybe other cases where type is added to the field name.
