- **Resolution Description**: Will update Group as follows:

Add all elements from the CanonicalResource Interface to Group and add Group to the context of the extensions which correspond to the additional elements defined on MetadataResource
Change Group.type 1..1 to 0..1 (with invariant that Group.type is required if Group.membership is definitional or enumerated)
Add 'conceptual' as a third choice to Group.membership 1..1 code
Add Group.combinationMethod 0..1 code (possibly as modifier?)
Add Group.combinationThreshold 0..1 positiveInt
Change Group.characteristic.value[x] to include uri | Expression among the allowed datatypes.
Add 7 elements to Group.characteristic, namely:

description 0..1 markdown
method 0..* CodeableConcept
determinedBy[x] 0..1 Reference(Device | DeviceDefinition | DeviceMetric) | Expression
offset 0..1 CodeableConcept (modifer=true)
instances[x] 0..1 Quantity | Range
duration[x] 0..1 Duration | Range
timing 0..* RelativeTime (multiple timings are interpreted as 'and')

- **Description**: There have been extensive discussions coordinated across HL7 Work Groups (BRR, CDS, CQI, LHS) and related activities (Vulcan RWD, Vulcan SOA, HEvKA/EBMonFHIR, Cohort Definition Connectathon Tracks) with consistent recommendations to provide a single method across many use cases in FHIR for defining the set of characteristics which represent the inclusion and exclusion criteria to be considered a member of a group, including groups of many types of entities (not necessarily specific to entities commonly represented with FHIR Resources). Having worked through element-level discussions in other spaces (including [Changes to Group for CohortDefinition and CohortDefinition Profile of Group Proposal ) the proposed changes to Group are:

Add most of the elements from the MetadataResource Interface to Group. (up to 23 elements to add)
Change Group.type 1..1 to 0..1 (with invariant that Group.type is required if Group.membership is definitional or enumerated)
Add 'conceptual' as a third choice to Group.membership 1..1 code
Add Group.combinationMethod 0..1 code
Add Group.combinationThreshold 0..1 positiveInt
Change Group.characteristic.value[x] to include uri | Expression among the allowed datatypes.
Add 6 elements to Group.characteristic, namely:

description 0..1 markdown
note 0..* Annotation
determinedBy[x] 0..* CodeableConcept | Reference(Device | DeviceMetric) | Expression
instances[x] 0..1 Quantity | Range
duration[x] 0..1 Duration | Range
timeFromEvent 0..* TimeFromEvent
