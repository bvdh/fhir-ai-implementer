# FHIR-44611: Scheduling workflow resources could use a better overview

## Metadata

- **Summary**: Scheduling workflow resources could use a better overview
- **Created**: 2024-01-30
- **Updated**: 2025-02-26
- **Resolved**: 2024-12-16
- **Status**: Applied
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Vadim Peretokin
- **Resolution**: Persuasive with Modification
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R5
- **Work Group**: FHIR Infrastructure
- **Related URL**: https://build.fhir.org/workflow-module.html
- **Related Page(s)**: Workflow Module
- **Resolution Description**: We will update the workflow module to include a sentence saying:

"For information about the relationship of specific domain resources, consult the modules that are specific to those resources. For example, the [Administration module] contains an explanation of the relationship of Appointment, Slot, Encounter, etc. The [Diagnostics module] contains the relationship between ObservationDefinition, ServiceRequest, Observation, DiagnosticReport, etc."
- **Resolution Vote**: Paul Lynch/Grahame Grieve: 9-0-0
- **Vote Date**: 2024-12-16
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Applied for Version**: R6
- **Description**: I've seen from practice that folks have a hard time understanding the boundaries between the Appointment, Slot, and Schedule resources. It would be great if a diagram (for the image-oriented) and some prose was added to the workflow module page that explained the relationships.

A good example is the finance module which does it well: https://build.fhir.org/financial-module.html
