- **Description**: As a definitional resource, SubstanceDefinition is used as part of defining knowledge artifacts, where the resource contents should be the same, regardless of the server on which the resource appears. Making SubstanceDefinition a canonical resource will allow the resource to be referenced as a canonical.

Many of the core canonical elements are already present on the resource, please consider adding:

url
title
experimental
date

And declare that the resource implements the CanonicalResource pattern.

In addition, with the resource as a canonical, the references can be canonical. Consider updating references to the resource to allow for canonical.
