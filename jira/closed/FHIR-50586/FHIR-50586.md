- **Resolution Description**: This is fixed for SampledData but is still broken for RelativeTime
- **Change Category**: Correction
- **Description**: On the main Datatypes page (http://hl7.org/fhir/6.0.0-ballot3/datatypes.html ), some data types don't have a box for their constraints, despite having some defined.

SampledData: sdd-1 doesn't appear

RelativeTime: rlt-1 and rlt-2 don't appear

These constraints still appear in the detailed view, e.g. http://hl7.org/fhir/6.0.0-ballot3/datatypes-definitions.html#SampledData.interval
