# FHIR-43305: Can Composite Search Parameters be nested?

- **Grouping**: AwaitingMerge
- **Resolution Description**: Will update the core spec to say that composite search parameters cannot reference other composite search parameters. Instead, construct the composite by pointing to the leaf-level search parameters of the 'desired' composite.
- **Resolution Vote**: Gino Canessa/Grahame Grieve: 15-0-1
- **Vote Date**: 2024-02-02
- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Applied for Version**: R6
- **Description**: Looking at an IG, we came across a composite search parameter that referenced another composite search parameter as one of the components.

The specification does not define if this is allowed or not. If it should be allowed, the Search Page should be modified to include an example. If it is not allowed, we should document the restriction and update tooling to reject.
