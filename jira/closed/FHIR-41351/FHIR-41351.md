# FHIR-41351: Operation `$snapshot` is an idempotent operation

- **Summary**: Operation `$snapshot` is an idempotent operation
- **Created**: 2023-05-30
- **Updated**: 2025-12-14
- **Resolved**: 2024-12-09
- **Status**: Applied
- **Project**: FHIR Specification Feedback
- **Type**: Change Request

- **Resolution**: Persuasive
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R5
- **Work Group**: FHIR Infrastructure
- **Related URL**: http://build.fhir.org/structuredefinition-operation-snapshot.html
- **Related Page(s)**: operations
- **Related Section(s)**: 5.4.12.2 Operation $snapshot on StructureDefinition
- **Resolution Description**: Will update text:

This is an idempotent operation. Snapshot generation is dependent on profiles that are referenced - if those profiles change, the snapshot can change. For a frozen package, $snapshot is idempotent.

We will also change affectsState to "false".
- **Resolution Vote**: Gino Canessa/Bryn Rhodes: 9-0-0

- **Description**: in FHIR [specification|http://build.fhir.org/structuredefinition-operation-snapshot.html] for `$snapshot` operation it is said that

```

This is not an idempotent operation

```

But it is an oversight, as snapshot generation is dependent on profiles that are referenced - if those profiles change, the snapshot can change.

Please, change this sentence to something like this:

```

This is an idempotent operation. Snapshot generation is dependent on profiles that are referenced - if those profiles change, the snapshot can change. For a frozen package, $snapshot should be idempotent.

```
