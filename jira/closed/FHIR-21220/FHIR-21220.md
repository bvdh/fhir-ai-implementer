- **Related Artifact(s)**: CodeSystem
- **Related Page(s)**: Metadata Types
- **Grouping**: Deferred
- **Resolution Description**: All metadata resources have a dedicated 'publisher' element. While there can be multiple editors, authors, reviewers, etc., there can only be one publisher (for HL7 resources). Introducing this new type would provide two ways to say the same thing.

This metadata type is being removed. Will delete the type as soon as it's removed from Statistic. Bryn will make sure this happens.

If you feel a need for more than one publisher, please bring the usecase forward on the implementers stream on Zulip for discussion. This might be supported via an extension.
