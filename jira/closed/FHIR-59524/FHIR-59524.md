- **Description**: The Medication search parameter serial-number searches the wrong element. Its expression is Medication.identifier, the business identifier of the Medication record. In R6 the serial number of a physical item is Medication.instance.identifier ("Identifier for the physical instance, typically a serial number"; see also FHIR-57429). Its build path extension (http://hl7.org/fhir/build/StructureDefinition/path) points to Medication.instance.lotNumber, which is the lot number.

FHIR-54379 corrected the description of serial-number ("Returns instance(s) of Medication resource that have this serial number"), but not the element it searches.

In the same file, the build path of lot-number still points to Medication.batch.lotNumber, an element that no longer exists (batch was renamed to instance in R6). The lot-number expression is already correct (Medication.instance.lotNumber).
