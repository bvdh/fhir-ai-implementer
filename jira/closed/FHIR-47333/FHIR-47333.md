- **Description**: Once a subscription is created, any triggering state change the specified SubscriptionTopic that meets the filtering criteria will cause a notification to be sent using the provided channel. Notifications are Bundle resources, of type subscription-notification.

The sentence could be improved and also might suggest it is a state change of the SubscriptionTopic resource. I suggest to rephrase as:

Once a subscription is created, any state change covered by the specified SubscriptionTopic that meets the filtering criteria will cause a notification to be sent using the provided channel. Notifications are Bundle resources, of type subscription-notification.
