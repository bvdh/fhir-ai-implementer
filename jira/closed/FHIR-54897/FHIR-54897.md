- **Description**: Our preference is to have a panel reported as a DiagnosticReport with multiple DiagnosticReports for items ordered on the same requisition included together in a bundle.

If we can not report a panel as a DiagnosticReport and a grouper of some type is going to be used then we would suggest creating a new grouper resource called Panel.. If a grouper resource called Panel can not be used then we would suggest using grouper observation and suggest a data absent reason of Grouper instead of the Observation.organizer indicator.
