- **Description**: We had several discussions on creating a "pattern" for referencing BodyStructure in resources. We aligned in general on an approach, where applicable, to have an element with data type CodeableReference (BodyStructure) and remove other elements, if present, that represent bodyStrcuture.
I see this resource does not follow this pattern. Please correct it or provide explanation (for example in Notes subsection) why the resource deviates rom the pattern.
