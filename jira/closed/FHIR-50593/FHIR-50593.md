- **Resolution Description**: It is unclear that there is enough usage to justify adding the element to the resource definition.

The recommendation is to use the existing extension: artifact-effectivePeriod.

Modify the contents of the TestScript resource to note that the extension could be present and describe at least one use case where it is applicable.

- **Description**: Should there be an additional field (like effectivePeriod from https://build.fhir.org/definition.html#Definition) added to TestScript?

I can imagine some tests would be valid/useful only during a pre-defined and known-ahead-of-time period, such as until a new regulation takes effect.
