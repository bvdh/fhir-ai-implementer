- **Description**: DiagnosticReport.Media - Key images or data associated with the report, but the link only references DocumentReference. If this is the description then the ability to reference ImagingSelection for this should be made as in ImagingSelection there is a note that the DocumentReference resource is used to store non-DICOM images, video, or audio with relevant metadata. Also ImagingSelection specifically calls out Key Object Selection in category. If this change in DiagnosticReport is to be made, then there will also need to be a corresponding update to ImagingSelection made in scope and usage.
