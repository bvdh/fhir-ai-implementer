# FHIR-50158: OperationDefinition needs additional bindings

## Metadata

- **Summary**: OperationDefinition needs additional bindings
- **Created**: 2025-04-01
- **Updated**: 2025-12-14
- **Resolved**: 2025-11-17
- **Status**: Applied
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Gino Canessa
- **Resolution**: Not Persuasive with Modification
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: FHIR Infrastructure
- **Related Artifact(s)**: OperationDefinition
- **Resolution Description**: We will add a best practice guideline saying that if there are bindings with a strength other than 'required' saying that they should be captured in the profile rather than the parameter definition.

We will explore whether we can improve the rendering of parameters to automatically also incorporate the rules expressed in the associated element in the corresponding input or output profile
- **Resolution Vote**: Grahame Grieve/Gino Canessa: 11-0-0
- **Vote Date**: 2025-11-17
- **Change Category**: Enhancement
- **Change Impact**: Non-substantive
- **Applied for Version**: R6
- **Description**: (Note that ElementDefinition is missing from the list of artifacts for R6 right now)

OperationDefinition.parameter currently has an element for binding, but does not include any additional bindings in the way that ElementDefinition does.

Propose adding OperationDefinition.parameter.binding.additional, matching the structure and content of ElementDefinition.binding.additional.

- **Jira**: https://jira.hl7.org/browse/FHIR-50158

## Comments

### 1. Lloyd McKenzie - 2025-11-17

The problem is that the rendering of the Operation parameters is misleading because essential constraints aren't visible. Someone looking only at the parameters will miss stuff - which essentially means that showing anything other than the parameter names is dangerous.

### 2. Josh Mandel - 2025-11-10

From discussion in FHIR-I: The goal of the parameters here is to nail down the wire format rather than to express the full details and all constraints; profiles can be used when more detail is needed.
