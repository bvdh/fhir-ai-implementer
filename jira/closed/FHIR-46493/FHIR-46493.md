## Comments

### 1. Gino Canessa - 2024-08-05

When using the subscriptions framework, sometimes a server wants to send notifications with queries instead of ids or full resources.

Concrete use cases presented include:

referrals for services that may be scheduled far into the future (ids of not-yet-created resources are not known)
complex versions of 'id' notification (e.g., using an operation to fetch a set of resources, etc. - specific case of insurance coverage has been discussed).

This has been discussed both at multiple WGMs and many ad-hoc sessions. A larger document with proposals can be found here.
