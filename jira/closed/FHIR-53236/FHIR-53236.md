# FHIR-53236: Does Medication.ingredient.item need Substance?

- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: Pharmacy
- **Related Artifact(s)**: Medication
- **Resolution Description**: We will replace the contained Substance resource with a code.
- **Change Category**: Correction
- **Applied for Version**: R6
- **Description**: For FHIR-43166 this element is getting a extra reference to SubstanceDefinition, so that definitions can still be carried, even though Substance resource no longer allows that.

I don't plan to remove the reference to Substance, in case an instance is needed.

Is the ingredient ever an actual known instance of a substance? Presumably yes, when Medication is an actual instance of a compounded drug (uncommon, but possible).

But if not, then Substance needs to be removed.
