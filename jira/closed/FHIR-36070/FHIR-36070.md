- **Description**: Value Sets and Code Systems should be marked Trial Use when bound to Trial Use elements in a Normative resource.

I noticed that CapabilityStatement has a number of "code" data type elements tagged as TU (such as CapabilityStatement.versioning), but the corresponding value set and code system are Normative.
