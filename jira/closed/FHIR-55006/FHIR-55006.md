### 4. Stephen Chu - 2026-04-07

Is the element isRecordOfRequest appropriate? Wouldn't that be a MedicationStatement?

MedicationRequest.isRecordOfRecord is a rename of MedicationRequest.reported
Like MedicationRequest.reported, MedicationStatement.isRecordOfRequest = true --> does not turn MedicationRequest into MedicationStatement.

There are use cases in which MedicationRequest information need to be exchanged faithfully but such MedicationRequest instances are not intended to be (and should not be) used to dispense medications

The IPS and AU-PS are typical examples.
IPS.Composition includes:
section:sectionMedications, which in turn includes:
entry:medicationStatementOrRequest 0..* Reference(MedicationStatement (IPS) | MedicationRequest (IPS))

The IPS and AU-PS need to faithfully exchange known MedicationRequest instances that are relevant to the context of the patient's condition and continuity or transition of care.
But ...
The MedicationRequest (IPS) instance(s) if included is | are not intended to be and should not be used to trigger any medication dispense or administration.
Yet, they are not MedicationStatements as they are intended to be faithful representation of the original prescription(s)
