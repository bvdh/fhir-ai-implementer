- **Description**: Recently an RFC for a new QUERY method for HTTP was published.

The current FHIR spec mentions GET and POST, also discusses where and why POST is better than GET for searching. https://www.hl7.org/fhir/search.html#transportprotocols

On the other hand, QUERY has the benefits of GET (better semantics and safer to use, for instance there are no side effects) and can hold a payload like POST. So it's basically designed for the search.

More info: https://datatracker.ietf.org/doc/html/rfc10008

I would put under consideration to add support for the QUERY HTTP method on future FHIR versions for doing the 'search' operation.
