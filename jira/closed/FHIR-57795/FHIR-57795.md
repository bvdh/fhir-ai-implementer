- **Description**: The BodyStructure example for a mass in the spleen was

in R4

morphology = "Mass (morphologic abnormality)"

location = "Splenic structure (body structure)"

https://hl7.org/fhir/R4/bodystructure-example-tumor.json.html

in R5

https://hl7.org/fhir/R5/bodystructure-example-tumor.json.html

morphology = "Mass (morphologic abnormality)"

includedStructure = "Splenic structure (body structure)"

in current R6 only

includedStructure = "Splenic structure (body structure)"

no morphology (lost?)

https://build.fhir.org/bodystructure-example-tumor.json.html

In R6 working version the morphology is a subelement of includedStructure. Should a

mass in the spleen (but not whole spleen) be described as

includedStructure[0] = "Splenic structure (body structure)"

includedStructure[0].morphology = "Mass (morphologic abnormality)"?

Generally, if the meaning is the mass is inside a structure, the R4 element "location" sounded obvious to use, whereas the BodyStructure.includedStructure = spleen sounds like the complete spleen is included in the BodyStructure.
If the includedStructure can still be used in the sense of location of the BodyStructure but not fully comprised in the BodyStructure, then this should be documented. I thought the example was documenting this in R5 as it said includedStructure = spleen, which is in fact the location, but not sure if that R5 example was intentional. And in R6 the example seems broken because the morphology was lost (I suspect, not sure).
But if BodyStructure.includedStructure should only be used in the sense that the includedStructure is fully included in the BodyStructure, then how is location of the BodyStructure now encoded? How will the example "mass inside the spleen" look now?

The BodyStructure example should be fixed in R6 and revisited together with other BodyStructure discussions about morphology, e.g. whether the morphology is needed on top level AND for each includedStructure and how to relate multiple BodyStructures. But I wanted to log a finding for the example in particular because that should document the how morphology and location of the morphology is expressed independent of which solution is selected in R6.
