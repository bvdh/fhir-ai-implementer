- **Description**: When isRecordOfRequest = true, the resource must not be treated as the actual medication request/order and must not be used for dispense, supply, or administration.

Ignoring this element could therefore lead to an incorrect interpretation of the resource.

Proposal:
Set isModifier = true for MedicationRequest.isRecordOfRequest.
