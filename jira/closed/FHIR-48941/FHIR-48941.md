- **Change Category**: Enhancement
- **Change Impact**: Non-compatible
- **Applied for Version**: R6
- **Description**: Update the cardinality on the definition property to support more than 1 value.

This would then support extraction into multiple resource types/profiles for the same item in a questionnaire.

e.g. To support populating both a resource and provenance from the same thing.

Or to create both a RelatedPerson, and also Patient.contact from the same data in a form item.

### 4. Lloyd McKenzie - 2024-12-05

For the SDC ballot, will include a note to balloters indicating that 'definition' will likely repeat and there will be an extension to convey additional repetitions. Will indicate that there is no meaning associated to which definition appears in the main 'definition' element vs. the extension. Systems may choose to only include the extension rather than the core element if they don't want to pick a single element from their list.

Will send the question of whether to change the cardinality or to add an extension to support extra repetitions. I.e. is a breaking change ok?
