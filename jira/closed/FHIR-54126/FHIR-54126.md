- **Resolution Description**: We will only refer to "no known medications", which matches the only concept in the value set. In the MedicationStatement Note to Balloters, change "statements such as 'no medications are known / taken.'" to "statements such as 'no known medications'." No concept for "no medications taken" is added.
We will use "no known medications" and not "no medications are known".

- **Change Category**: Clarification
- **Change Impact**: Non-substantive
- **Description**: The 'no medications known' seems different than 'no medications taken'. In the value set, only the concept 'No known medications' is listed.
The MedicationStatement.medication element now explicitly supports representing statements such as 'no medications are known / taken.'

Either

only include 'No known medications' in the text and value set
add a new concept for 'no medications taken'
