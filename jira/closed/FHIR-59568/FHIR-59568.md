- **Resolution Description**: Change the mdd-1 expression to (whenHandedOver.hasValue() and whenPrepared.hasValue()) implies whenHandedOver.highBoundary() >= whenPrepared.lowBoundary(): the warning is raised only when the handover is certainly before the preparation. This is the pattern already used by the Period and Range invariants (for example start.lowBoundary() <= end.highBoundary()). Description unchanged.
Do not add mdd-2: a handover recorded with a date only, on the same day as the preparation, is valid and common; a warning for it would be raised on correct data without pointing to an error.

If whenPrepared is "2026-09-20T16:42:00Z" and whenHandedOver is "2026-09-20" so they're both the same day but whenPrepared has the time precision but not whenHandedOver when the >= comparison is done, the expression will resolve as false (incorrectly) even if whenHandedOver did occur later just didn't have the time recorded.

For that kind of comparison, FHIRPath describes using lowBoundary and highBoundary. So I suggest adding .highBoundary() to whenHandedOver and .lowBoundary() to whenPrepared for the dateTime comparison.

(whenHandedOver.hasValue() and whenPrepared.hasValue()) implies whenHandedOver.highBoundary() >= whenPrepared.lowBoundary()

Like that. But having an unknown time could still be a different warning since it's unknown one way or the other. So if you have whenHandedOver and whenPrepared on the exact same date but at least one of them has an unknown time, you don't really know for sure which one came before the other.

So you could have a new constraint, mdd-2, that specifically targets that situation like this:

(whenHandedOver.hasValue() and whenPrepared.hasValue() and whenHandedOver.precision() >= 8 and whenPrepared.precision() >= 8 and whenHandedOver.lowBoundary(8) = whenPrepared.lowBoundary(8)) implies (whenHandedOver.precision() > 8 and whenPrepared.precision() > 8)

Of course there could be other ways to write the expression too.

And the description could be: "Both whenHandedOver and whenPrepared are recorded for the same date, but at least one of them doesn't have the time of day. It is unknown whether or not the handover occurred before preparation."

The point of adding mdd-2 is to give a more accurate warning about the issue.
