- **Resolution Description**: Will ensure that, for "shared" search parameters, the resources that make use of normative search parameters where the resources themselves are not normative automatically spit out a "standards status" extension on the "base" element for the non-normative resources indicating that the search parameter is either 'STU' or 'Draft' for that element, based on the status of the resource. Will also ensure that this resource-specific status of the search parameter is reflected in the rendering of the search table.

We noticed that some of the query parameters defined on topic are listed as normative, though it's possible the fields they search by would be added/removed/changed. This seems incorrect.
