- **Resolution Description**: We won't necessarily always have ActorDefinitions defined when we want to use ExampleScenario, and requiring the creation of one (Even as a contained resources) is a fair amount of overhead
The 'title' and 'description' for an actor in the context of a particular ExampleScenario might be more refined/specific than what's found on the ActorDefinition itself, so these elements still have value

We will add a 'requirements' note on the 'title' and 'description' elements that explains this decision.
