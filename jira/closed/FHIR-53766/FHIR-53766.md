- **Specification**: FHIR Core (FHIR)

- **Work Group**: FHIR Infrastructure
- **Related Artifact(s)**: CanonicalResourceCapabilityStatement (Conformance)CodeSystemConceptMapGraphDefinitionImplementationGuideMessageDefinitionNamingSystemOperationDefinitionSearchParameterStructureDefinitionStructureMapValueSet
- **Grouping**: Applied
- **Resolution Description**: We remove the "deprecation" flag from the jurisdiction property on the CanonicalResource, and all the subsequent derived resources.
- **Change Category**: Correction
- **Change Impact**: Non-substantive
- **Description**: https://jira.hl7.org/browse/FHIR-48492 removed the deprecation flag from the "jurisdiction" element of conformance resources.

However, these elements still have a "DEPRECATION NOTE" in their comment field that wasn't removed. For example: https://build.fhir.org/operationdefinition-definitions.html#OperationDefinition.jurisdiction
DEPRECATION NOTE: For consistency, implementations are encouraged to migrate to using the new 'jurisdiction' code in the useContext element. (I.e. useContext.code indicating http://terminology.hl7.org/CodeSystem/usage-context-type#jurisdiction and useContext.valueCodeableConcept indicating the jurisdiction.)
This sentence should be removed or rephrased, since these elements are no longer deprecated. Note that these elements already have an updated Description to indicate when to use this element vs. useContext.
