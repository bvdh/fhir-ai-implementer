- **Resolution Description**: Remove the 'Trial Use' tags from the conditional interaction content on the HTTP page - they have existed since DSTU2.

Similarly, remove the TU flags for the relevant elements on CapabilityStatement.rest.resource for these interactions.

Add the following codes, based on existing functionality:

create-conditional: Create a new resource with a server assigned id if an equivalent resource does not already exist.
update-conditional: Update an existing resource based on some identification criteria (or create it if it is new).
patch-conditional: Update an existing resource, based on some identification criteria, by posting a set of changes to it.
delete-conditional-single: Delete a single resource based on some identification criteria.
delete-conditional-multiple: Delete one or more resources based on some identification criteria.

Note: also add the following codes, per https://jira.hl7.org/browse/FHIR-16198 :

delete-history: Delete all historical versions of a resource.
delete-history-version: Delete a specific version of a resource.

- **Description**: Conditional interactions are currently not included in the RESTful interaction Code System:

https://hl7.org/fhir/codesystem-restful-interaction.html

Propose that we add the existing conditional interactions (e.g., conditional create) as well as the version-specific deletions being added in R6.
