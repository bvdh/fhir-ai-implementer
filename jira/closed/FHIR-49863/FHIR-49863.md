- **Resolution Description**: We will change the 'reported' element on MedicationRequest to be named 'isRecordOfRequest' and note that it maps to the 'reported[x] boolean' element on the Request workflow pattern.

We will make it a modifier element.

We will change the short of the element to be:

Whether this is record of a Medication Request or the actual request itself.

We will change the description of the element to be:

The information in this instance is a record of the Medication Request and is not request or order itself and should not be considered as such, i.e. the information should not be used for medication dispense | supply and administration.

- **Description**: MedicationRequest resource includes the following elements:
MedicationRequest.status
valueset = active | on-hold | ended | stopped | completed | cancelled | entered-in-error | draft | unknown
MedicationRequest.intent
valueset = proposal | plan | order | original-order | reflex-order | filler-order | instance-order | option
MedicationRequest.reported
boolean = yes | no

MedicationRequest is used in IPS IG, and will be used in Australian Patient Summary IG (which is derived from IPS)
It will also be used in Australia's Aged Care Clinical Document FHIR IG
These use cases are to support: continuity of care, transition | transfer of care, collaborative care.

In all these use cases, the purpose of including MedicationRequest is to communicate that there is a set of known medication requests | orders for the subject (target patient). The MedicationRequest information included is to communicate that it is a record of Medication Requests, not the Medication Request themselves.

While setting MedicationRequest.reported value to Yes or True may to some degree carry the semantic that it reported data, but not the request or order itself and should not be considered as such, i.e. the information should not be used for medication dispense | supply and administration

However, two other MedicationRequest data elements add confusion:
MedicationRequest.status = active
MedicationRequest.intent = order
In such case:
What does it mean when the MedicationRequest.reported = yes | true?

To provide the absolute semantic clarity, this request is for Pharmacy WG to consider addition of a modifier data element to the base resource, or a modifier extension element:
MedicationRequest.recordOfRequest
Definition = This is a record of medication request only to support continuity of care and transition of care, It is not a original medication request itself
Comment: this MedicationRequest instance should not be used as order for dispensing or administration medication.
