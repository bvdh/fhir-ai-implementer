- **Description**: isRecordOfRequest fundamentally changes the interpretation of the element or resource (it's not a real order), but it's NOT marked as a modifier element.

From isRecordOfRequest definition: " ...is not request or order itself and should not be considered as such, i.e. the information should not be used for medication dispense | supply and administration."

Propose making it a modifier element.

### 2. Lloyd McKenzie - 2026-01-25

Request resources are always records of requests. For them to be authoritative, they need a tag. However, I'd question the existence of the element entirely. Why do we have an element that's doing something that the tag is intended for? The reason for using a tag rather than the element is to avoid breaking signatures when you copy an order from one system to another and need to change "isActionable" but want to retain signature validity.
