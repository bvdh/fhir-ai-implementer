# FHIR-44817: Clarify whether a resource id is a String

- **Work Group**: FHIR Infrastructure
- **Related Page(s)**: FHIRPath (fluentpath)
- **Resolution Description**: Make it clear that Patient.id is a FHIR.id and Patient.id is not a System.String.

We realize that the StructureDefintions suggest otherwise. And we are creating a task to propose changes for clarity.

The intention of this is that we want to say Resource.id is an id (datatype), but cannot have extensions. There had been no way to express this, so that is why the definitions look this way.

I believe the following should be true, but it is not obvious:

1) Patient.id is System.String = true
2) Patient.id is FHIR.id = false
