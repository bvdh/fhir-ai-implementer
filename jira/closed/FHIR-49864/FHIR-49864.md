- **Description**: In transition of care | transfer of care use cases, e.g. in Australia's Aged Care transfer summary or Aged Care Clinical Documents, there is a need also to include MedicationDispense information (in addition to MedicationRequest)

Some of the MedicationRequest includes number of repeats
For example: Pulmicort Turbuhaler 400 mcg/ACT inh (budesonide)
Number of repeats = 5
When a Aged Care Transfer Summary is sent (e.g. from one aged care facility to another when the patient moves interstate to be closer to family), the clinical document needs to include record of MedicationRequest - MedicationDispense record pairs
The purpose is to inform receiving aged care facilities that the patient has, e.g. a prescription of Pulmicort with 5 repeats, and the MedicationRequest instance indicating 2 of the 5 has already been dispensed (to meet, e.g. Medicare authorisation requirements)
In Australia, currently this requirement is supported by paper system - see image attached
In the Aged Care transfer use cases, an electronic solution is required.

The FHIR MedicationDispense resource does not include the following modifier data elements:
MedicationDispense.numberOfRpeatsAuthorised
Definition = number of repeats dispense as authorised in the MedicationRequest
MedicationDispense.numberDispensed
Definition = number of times (out of the total authorised repeat) already dispensed (including the original supply)

It is preferable that these modifier elements are included in the base resource.
Alternate option is to add these as modifier extension elements
