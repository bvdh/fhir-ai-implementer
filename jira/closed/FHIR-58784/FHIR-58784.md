- **Resolution Description**: Requires fix in Firely tooling. Use of local URLs is widespread in FHIR spec and is the correct approach.
- **Description**: The core FHIR StructureDefinition for ImagingStudy has the following comment for ImagingStudy.identifier:
"comment" : "See discussion under [Imaging Study Implementation Notes](imagingstudy.html#dicom-uids) for encoding of DICOM Study Instance UID.",

Because of the use of a relative URL instead of an absolute URL, profiles that derive from resource will end up a broken link (YourURLHere.com/imagingstudy.html#dicom-uids), rather than point to be base FHIR spec.

For example, this profile of ImagingStudy https://simplifier.net/PS-CA-R1/ImagingStudyPSCA/~overview (produced using fsh/sushi) ends up with a link to https://simplifier.net/PS-CA-R1/ImagingStudyPSCA/imagingstudy.html#notes under the comment.
