ImagingSelection.instance.referencedContentItemIdentifier

Element Id
ImagingSelection.instance.referencedContentItemIdentifier

Definition
A sequence of positive integers that identify a single list of Referenced Content Item Identifier values selected from a DICOM SR or other structured document SOP Instance (See DICOM PS3.3 C.17.3.2.5 ).

Short Display
Selected content items

Comment
The Content Item Identifier is only reliably if the order of sequence items in the referenced DICOM SOP Instance is consistent. Some applications may re-order sequence items, invalidating this reference.

- **Description**: This concerns is also pending the decision on https://jira.hl7.org/browse/FHIR-57940 "References into content items of a DICOM SR not allowed in DICOM"

If the above mentioned ticket is rejected, the encoding of the ImagingSelection.instance.referencedContentItemIdentifier should be changed to either a different value type or the single values of the reference content item should be children of the ImagingSelection.instance.referencedContentItemIdentifier to map to the hierachical structure of content items in DICOM SR. Otherwise it is not evident that the multiple values need to be seen as the complete reference into one hierachical content item of the SR.

If non of the above is realized at least a description how to create such a reference into an SR Content item should be given

Note that this would also include a change of
