We're not thinking that markdown is appropriate here. We think that given that this is supposed to be computable content and that we don't necessarily want the 1 million character limit to apply, should use Attachment. If you want a pretty-print version of the content, could have a markdown extension for that. Alternatively, we could have the publisher auto-pretty-print certain languages (like we do for XML/JSON).
