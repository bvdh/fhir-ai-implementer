# FHIR-43224: sdf-5 is too strict

## Metadata

- **Summary**: sdf-5 is too strict
- **Created**: 2023-11-24
- **Updated**: 2025-03-02
- **Resolved**: 2024-04-22
- **Status**: Applied
- **Project**: FHIR Specification Feedback
- **Type**: Change Request
- **Reporter**: Elliot Silver
- **Resolution**: Persuasive
- **Specification**: FHIR Core (FHIR)
- **Raised in Version**: R6
- **Work Group**: FHIR Infrastructure
- **Related Artifact(s)**: StructureDefinition
- **Resolution Description**: Will change "type != 'Extension' or derivation = 'specialization' or (context.exists())" to

"type != 'Extension' or base != 'http://hl7.org/fhir/StructureDefinition/Extension' or derivation = 'specialization' or (context.exists())"
- **Resolution Vote**: Josh Mandel/Christiaan Knaap: 8-0-0
- **Vote Date**: 2024-04-22
- **Change Category**: Correction
- **Change Impact**: Non-substantive
- **Description**: sdf-5 requires a context for any extension, including reprofiled extensions. A reprofiled extension shouldn't require a context since it should inherit the base extension's context.

See https://chat.fhir.org/#narrow/stream/179252-IG-creation/topic/Reprofiling.20extension
